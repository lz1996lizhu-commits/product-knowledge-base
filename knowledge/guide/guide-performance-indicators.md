# 绩效指标制定指南

## 适用角色

- 绩效HR专员（统一派发、流程监控）
- 经理人/部门负责人（审核确认、下达指标）
- 员工（自主制定、提交审核）

## 支持的考核模式

| 模式 | 特点 | 适用场景 |
|------|------|----------|
| KPI | 关键绩效指标，聚焦核心产出 | 目标明确、可量化的岗位 |
| BSC | 平衡计分卡（财务/客户/运营/学习发展四维度） | 管理层综合评估 |
| PBC | 个人绩效承诺 | 自主承诺+上级确认的灵活模式 |
| 综合考核 | 多种模式组合（如KPI+态度+行为+能力） | 需要多维度评估的场景 |

## 指标制定方式

### 方式一：HR统一派发（自上而下）

适用场景：董事会/管理层决策后的战略目标分解

操作步骤：
1. 进入考核计划，选择目标考核活动
2. 选择"统一派发"模式
3. 按分组批量添加指标（支持从指标库选取、复制历史指标、Excel导入）
4. 配置指标权重、目标值
5. 启动制定流程，系统自动派发至对应员工

### 方式二：员工自主制定（自下而上）

适用场景：员工根据岗位职责自主制定目标

操作步骤：
1. 员工收到制定任务通知
2. 登录系统进入个人绩效工作台
3. 根据岗位职责和上级要求自主添加指标
4. 填写目标值、权重、完成标准
5. 提交给上级审核

### 方式三：部分派发+自主制定（上下结合）

适用场景：固定指标统一派发 + 个性化指标自行制定

操作步骤：
1. HR先统一派发部分固定指标（如财务类、职能类）
2. 员工在派发基础上补充自主制定的指标
3. 经理人审核全部指标并确认

### 方式四：矩阵式指标下达

适用场景：不同员工需要不同指标的差异化管理

操作步骤：
1. 在考核计划中配置矩阵式下达方案
2. 按员工维度（组织、职位等）匹配不同的指标集
3. 系统自动下达对应指标
4. 员工可在此基础上调整

## 快捷添加指标方法

- **从指标库选取**：调用企业预置的标准指标库
- **复制历史制定分组指标**：复用上期相同分组的指标配置
- **复制制定对象历史指标**：复用特定员工的历史考核指标
- **Excel导入**：通过预设模板批量导入指标数据

## 指标制定流程监控

### HR视角操作

1. 启动制定流程前：检查制定人设置，支持手动或动态获取
2. 流程启动后：
   - 实时监控各制定环节进度
   - 针对异常场景灵活设置/调整/退回处理人
   - 对停留时间较长的任务进行催办
   - 支持任务汇总后发送，避免频繁打扰处理人

### 经理人审核操作

1. 收到审核任务通知（支持合并相同活动的制定任务）
2. 多任务合并视图，快捷切换制定对象
3. 多维度筛选制定对象（制定状态、部门、岗位等）
4. 批量审核操作

## 注意事项

- 不同考核模式下的指标制定流程不同，请根据考核计划配置选择对应方式
- 指标制定支持多级审核、多级确认
- 制定过程中如发生人事变动，需及时调整处理人
- 建议在启动前检查制定人配置是否正确
