# 新用户入门指南

## 第一步：注册账号

1. 访问系统首页，点击"立即注册"
2. 填写邮箱、手机号、设置密码
3. 完成邮箱/手机验证
4. 注册成功，自动跳转到首页

## 第二步：完善个人信息

1. 点击右上角头像进入"个人中心"
2. 上传头像、填写昵称
3. 绑定其他联系方式（可选）

## 第三步：熟悉基本功能

- **首页**: 查看最新动态和推荐内容
- **工作台**: 管理日常任务和待办事项
- **消息中心**: 接收系统通知和协作消息
- **设置**: 调整偏好设置和账户安全

## 第四步：开始使用

建议新用户按照以下顺序体验核心功能：

1. 创建第一个项目/任务
2. 邀请团队成员加入
3. 体验协作功能
4. 探索高级功能

## 获取帮助

- 使用系统内置帮助中心（右下角?图标）
- 联系客服：support@example.com
- 查看视频教程（设置 > 帮助 > 视频教程）
