# 录用通知书模板（Offer Letter模板）

# 总体介绍

## **1 功能介绍**

该功能支持对录用通知书的模板进行自定义创建、编辑、保存等配置操作，可标准化录用通知书的内容格式，解决企业录用通知书样式不统一、重复编辑效率低的问题，实现录用通知书的快速生成与发放。

## **2 应用场景**

当企业开展招聘工作，需要向拟录用人员发放标准化的录用通知书时，可通过该功能配置专属的录用通知书模板，适配不同岗位、不同招聘类型的录用通知需求；当录用通知信息项（如薪资构成、入职要求、福利待遇）发生调整时，可通过该功能对已有模板进行修改配置，确保通知书内容的准确性。

## **3 系统路径**

人才供应云 > 招聘基础服务 > 业务配置 > 招聘服务直通车 > 录用通知书模板

## **4 主要操作**

| **操作名称** | **操作简介** |
| --- | --- |
| 新增录用通知书模板 | 适用于企业首次配置录用通知书模板，或需要为不同场景创建专属模板的业务场景，解决无标准模板可用的问题。 |
| 修改录用通知书模板 | 适用于企业录用通知信息项、格式要求发生变更的业务场景，解决原有模板内容不符合当前业务需求的问题。 |
| 删除录用通知书模板 | 适用于清理无用或过期的录用通知书模板的业务场景，解决模板列表杂乱、查找效率低的问题。 |
| 设置默认模板 | 支持设置一个默认的录用通知书模板，默认模板会被优先使用。 |
| 配置常用变量 | 配置录用通知书中可使用的变量字段。 |
