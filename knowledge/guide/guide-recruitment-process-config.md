# 招聘流程

# 总体介绍

## **1 功能介绍**

招聘流程配置支持企业根据自身招聘业务需求，自定义设置招聘流程所包含的招聘环节及各环节对应的状态，将环节与状态按需组合，形成标准化的招聘流程，实现招聘流程的规范化与个性化管理，适配不同岗位、不同招聘场景的流程管控需求。

## **2 应用场景**

当企业开展招聘管理工作并需要统一规范招聘全流程的环节节点与状态标识时，可使用该功能配置招聘流程；企业新增招聘岗位类型、调整招聘业务流程或优化招聘环节管控要求时，也可通过该功能对招聘流程进行新增、修改或调整，确保招聘流程与实际业务匹配。

同时，不同事业部、业务线有差异化招聘流程需求时，可单独配置专属招聘流程，满足多场景招聘管理需求。

## **3 系统路径**

人才供应云 > 招聘基础服务 > 业务配置 > 内部招聘 > 招聘流程

## **4 主要操作**

| **操作名称** | **操作简介** |
| --- | --- |
| 新增招聘流程 | 适用于企业新增个性化招聘流程的场景，可按需选择招聘环节并设置环节状态，组合生成新的招聘流程，解决不同招聘场景无对应标准化流程的问题。 |
| 修改招聘流程 | 适用于企业已有招聘流程需调整环节或状态的场景，可对流程内的环节进行增删或状态修改，解决招聘业务流程变更后系统流程不匹配的问题。 |
| 删除招聘流程 | 适用于企业存在无效、闲置招聘流程的场景，可清理无用流程，解决系统内流程冗余、管理混乱的问题。 |
| 配置招聘环节 | 适用于自定义招聘流程框架的场景，可选择简历筛选、初试、复试、终面、录用等招聘环节，解决招聘环节缺乏统一配置、流程不规范的问题。 |
| 配置环节状态 | 适用于对各招聘环节进行精细化管控的场景，可为每个环节配置待处理、处理中、通过、不通过等状态，解决招聘环节进度无明确标识、管控不清晰的问题。 |
