# 绩效考核活动流程

## 流程概述

绩效考核活动是目标绩效云的核心业务流程，涵盖从考核计划建立到结果应用的完整生命周期。支持按周期、人群、政策、流程搭建差异化的考核方案。

## 流程阶段

考核计划建立 → 指标制定 → 绩效执行与辅导 → 绩效评估 → 结果汇总 → 结果校准 → 结果确认 → 结果应用

## 详细步骤

### 1. 考核计划建立

- 负责人：绩效HR专员
- 操作：建立考核计划、设置评估对象分组、选择考核模板与流程
- 说明：根据战略目标建立周期性考核计划。支持多周期组合（年+季度、年+月度等），支持多级分组管理评估对象（按部门、职位、职级、序列分组），每个分组可差异化设置表单和流程。

### 2. 指标制定

- 负责人：HR/经理人/员工
- 操作：统一派发或自主制定指标，多级审核确认
- 制定方式：
  - HR统一派发（自上而下）
  - 员工自主制定+上级审核（自下而上）
  - 部分派发+部分自主（上下结合）
  - 矩阵式指标下达
- 说明：支持KPI、BSC、PBC等多种考核模式。可从指标库快捷添加、复制历史指标、Excel导入。制定过程实时监控，支持催办和调整处理人。

### 3. 绩效执行与辅导

- 负责人：经理人/员工
- 操作：目标执行跟踪、定期复盘、反馈沟通
- 说明：支持任务跟进、绩效回顾、绩效辅导、指标变更等过程管理活动。

### 4. 绩效评估

- 负责人：员工/直线经理/间接上级/HRBP
- 操作：按配置流程多角色参与评估
- 评估方式：
  - 员工自评
  - 交叉评分（HRBP/业务主管）
  - 直接上级评估（整单评分）
  - 间接上级评估（评总分/调整总分）
  - 审计评估
- 说明：支持多人对比评估视图，自动合并相同活动评估任务。支持批量高效评估。评估进度可实时管理和干预。

### 5. 结果汇总

- 负责人：绩效HR专员
- 操作：汇总各周期、各维度评估结果
- 说明：支持多周期汇总、多任职汇总、综合汇总。支持自定义汇总数据类型和按组/按个人调整汇总规则。

### 6. 结果校准

- 负责人：绩效HR专员/部门负责人
- 操作：按正态分布规则进行结果校准
- 说明：支持按分数段转等级或按排名转等级，支持自定义校准组（按行政组织、复制等方式批量建立），支持多次校准。提供实时校准后等级分布查看和人员信息对比视图。

### 7. 结果确认

- 负责人：员工/经理人/HR
- 操作：多级确认审批
- 说明：支持员工对考核结果确认（认同/不认同），系统完整记录确认流程。协商后支持再次确认。

### 8. 结果应用

- 负责人：HR
- 操作：将绩效结果应用于薪酬激励、人才晋升、管理退出、人才盘点、培训提能
- 说明：绩效结果记录在个人绩效档案中，供后续业务决策参考。

## 考核计划结构

```
考核计划
├── 周期设置（年/半年/季/月）
├── 评估对象范围（多个考核组）
│   ├── 考核组1（如：高管）
│   │   ├── 考核方法：BSC+KPI+360+领导力评估
│   │   └── 各周期执行计划
│   ├── 考核组2（如：中基层管理者）
│   │   ├── 考核方法：KPI+能力+价值观
│   │   └── 各周期执行计划
│   └── 考核组3（如：普通员工）
│       ├── 考核方法：KPI+态度评价
│       └── 各周期执行计划
└── 年度汇总
```

## 关键配置要素

- 评估表单：支持多区域配置（指标字段、评价字段、完成字段、总评字段等）
- 绩效流程：图形化+卡片化工作流配置，预置通用节点
- 等级规则与评分分制：差异化配置
- 正态分布规则：校准规则定义
