# 继任计划全流程

## 流程概述

继任计划旨在识别企业关键岗位并进行岗位继任梯队的分层选拔、任用和发展，保障关键岗位人才供给的连续性，降低核心岗位人才断层风险。覆盖从关键岗位识别到继任者发展的完整生命周期。

## 流程阶段

关键岗位识别 → 继任梯队搭建 → 继任者选拔 → 继任者发展 → 继任地图生成 → 继任者任用

## 详细步骤

### 1. 关键岗位识别

- 负责人：人才发展专员/HRBP
- 操作：基于规则批量引用组织的岗位/职位，生成关键岗位，维护关键岗位要求
- 说明：基于企业战略和业务重要性，识别对业务连续性至关重要的岗位。支持基于规则批量引用组织的岗位/职位，生成关键岗位。关键岗位基本信息包括联查岗位/职位在任者、职位序列、职位族等。关键岗位要求引用组织的岗位/职位要求，并对关键岗位进行维护和管理。

### 2. 继任梯队搭建

- 负责人：人才发展专员/HRBP
- 操作：基于关键岗位能力分层选拔继任者，形成继任梯队
- 说明：基于关键岗位的能力要求，分层选拔继任者，形成继任梯队。继任梯队管理支持添加、移除、修改继任者，触发继任审核/审批流程。支持人才卡横向对比多位候选人，更直观地判断孰优孰劣，辅助提名决策。继任历史以"关键岗位"为视角，追溯历史，用户可查看过往所有继任者变更的修改记录。

### 3. 继任者选拔

- 负责人：HRBP/部门负责人
- 操作：提名继任候选人，发起继任申请，审核审批
- 说明：基于关键岗位继任梯队，HRBP或部门负责人提名继任候选人，发起继任申请单。申请单记录候选人信息、提名理由、继任准备度等。支持多级审核审批，确保继任者选拔的公正性和准确性。

### 4. 继任者发展

- 负责人：HRBP/人才发展专员
- 操作：跟进继任者培训学习进展，记录培养事件
- 说明：为继任者制定个性化发展计划，跟进培训学习进展。继任者视图记录继任者完整的发展轨迹，包括基本信息、关键岗位提名历史、培养事件记录等。支持联查在继任选拔过程中需要辅助决策的个人信息，如任职经历、教育经历等。

### 5. 继任地图生成

- 负责人：人才发展专员
- 操作：基于组织架构与继任计划生成继任地图，可视化继任储备情况
- 说明：支持基于组织架构按照配置层数展开继任地图，可视化展示关键岗位的继任储备情况。支持查看现任者和继任者的人才卡，多维人才对比。支持继任地图的下载与导出，辅助管理层决策。

### 6. 继任者任用

- 负责人：HR/审批领导
- 操作：当关键岗位出现空缺时，从继任者中选拔任用
- 说明：当关键岗位出现空缺时，从继任梯队中选拔合适的继任者进行任用。继任者可进入干部任免流程，完成正式任命。任用后系统自动更新继任历史记录，保持继任计划的连续性。

## 参与角色

| 角色 | 职责 |
|------|------|
| 人才发展专员 | 识别关键岗位、搭建继任梯队、生成继任地图、统筹继任计划 |
| HRBP | 提名继任候选人、跟进继任者发展、提供推荐意见 |
| 部门负责人 | 提名继任候选人、参与审核审批 |
| 继任者 | 参与培养计划、提升能力 |
| 审批领导 | 审批继任申请 |
