# 干部管理全流程

## 流程概述

干部管理旨在打造更高效、规范、全面的干部梯队管理应用，提供从"任"到"免"的全业务过程管理能力。覆盖干部任命、任期管理、免职的完整生命周期，支持常规任免和快速任免两种模式。

## 流程阶段

酝酿动议 → 任命提名 → 资格审查 → 考察评估 → 公示发布 → 审批签发 → 任期管理 → 免职申请

## 详细步骤

### 1. 酝酿动议

- 负责人：HRBP/部门负责人
- 操作：针对管理岗发起酝酿动议单，初步选拔任命候选人
- 说明：当企业出现管理岗空缺时，通过酝酿动议初步选拔任命候选人。酝酿动议单记录岗位信息、候选人初步信息、动议原因等。

### 2. 任命提名

- 负责人：HRBP/部门负责人
- 操作：录入拟任信息及推荐信息，发起任命申请流程
- 说明：在酝酿动议基础上，录入详细的拟任信息（拟任岗位、拟任职级等）和推荐信息（推荐理由、推荐人等），发起正式的任命申请流程。

### 3. 资格审查

- 负责人：HR/组织部门
- 操作：对候选人进行资格条件审核
- 说明：对候选人的基本条件、任职资格、履历信息等进行审核，确认是否满足任命的前置条件。支持多级审核，审核结果作为后续考察的依据。

### 4. 考察评估

- 负责人：考察组/HRBP
- 操作：对候选人进行综合考察
- 说明：对候选人进行综合考察，包括民主测评、个别谈话、实地走访、专项调查等。考察结果形成考察报告，作为任命决策的重要依据。支持考察协作，多人协同完成考察任务。

### 5. 公示发布

- 负责人：HR/组织部门
- 操作：对拟任人员进行公示
- 说明：对通过考察的拟任人员进行公示，公示周期、范围可自定义。公示消息按模板触达指定人群，公示周期内可接收反馈或驳回。公示结果作为最终任命的参考。

### 6. 审批签发

- 负责人：审批领导/HR
- 操作：完成审批流程并签发任命
- 说明：完成多级审批流程后，签发正式任命文件。审批流程可根据企业实际情况配置，支持会签、或签等多种审批方式。签发后系统自动记录任命信息，更新干部履历。

### 7. 任期管理

- 负责人：HR/HRBP
- 操作：记录任期关键信息，跟踪任期进展
- 说明：在干部上岗后记录任期的关键信息，包括任期起止日期、任期目标、履职情况等。支持任期报表，实时了解干部任期状态。当出现任期期满或履职不合格时，可发起免任动作。

### 8. 免职申请

- 负责人：HRBP/部门负责人
- 操作：当任期期满或履职不合格时，发起免职申请
- 说明：当干部任期期满、履职不合格、或其他原因需要免职时，发起免职申请流程。免职申请需说明免职原因，经审批后完成免职操作，系统自动更新干部履历。

## 任免模式

### 常规任免

适用于包含多项评估活动（如资格审查、考察、公示等）的任免场景。完整覆盖酝酿动议、任命提名、资格审查、考察、公示、签发等全部环节。

### 快速任免

适用于无需评估活动的任免场景。简化流程，直接进行任命提名和审批签发，适用于平级调动、简单任命等场景。

## 参与角色

| 角色 | 职责 |
|------|------|
| HRBP | 发起酝酿动议、任命提名、免职申请，跟踪任免进展 |
| 部门负责人 | 提名候选人、参与考察、提供推荐意见 |
| HR/组织部门 | 资格审查、公示管理、审批流程管理 |
| 考察组 | 综合考察候选人，形成考察报告 |
| 审批领导 | 审批任命/免职申请 |
| 干部本人 | 查看任命信息、任期信息 |
