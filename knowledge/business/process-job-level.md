# 职级评定全流程

## 流程概述

职级评定旨在打通内部发展通道，激励员工自我提升。基于职位体系和能力素质模型，科学建立结构化职级标准，通过职级评定全流程管理，帮助企业客观评估人才在当前职位上的履职表现和综合能力。覆盖从职级标准建立到结果应用的完整生命周期。

## 流程阶段

职级标准建立 → 评定计划创建 → 晋升提名 → 职级申报 → 资料复核 → 评审安排 → 评审评议 → 结果决议 → 结果报批 → 结果应用

## 详细步骤

### 1. 职级标准建立

- 负责人：人才发展专员
- 操作：结合职位体系方案，基于职位及其关联的职等范围，定义各职等的素质要求，形成结构化的职级（职等）标准
- 说明：结合职位体系方案，基于职位及其关联的职等范围，通过引入能力素质模型定义各职等的素质要求，形成结构化的职级（职等）标准。支持在制定标准的同时定义申请资格（常规通道晋升、绿色通道晋升）与评议形式，从而支撑对某一职位完整的职级（职等）评定流程。

### 2. 评定计划创建

- 负责人：人才发展专员
- 操作：创建周期性的职级评定计划，自定义年龄、司龄、现职等龄统计截止日期，定义评定对象范围
- 说明：支持用户创建周期性的职级评定计划，并根据企业需求自定义年龄、司龄、现职等龄统计的截止日期，便于判断员工是否满足申报条件。在评定计划中，支持按组织与职位职等自定义评定对象范围，分层分级开展职级评定流程。

### 3. 晋升提名

- 负责人：HR/部门负责人
- 操作：系统自动生成可提名员工名单，HR下发至部门负责人，部门负责人完成提名调整
- 说明：基于评定计划，系统自动生成本次计划中可提名员工的名单，并基于申请资格智能提供晋升建议。HR将自动生成的名单下发至部门负责人后，部门负责人根据员工履职表现完成提名调整。支持批量提名、提名审核。

### 4. 职级申报

- 负责人：员工/HRBP
- 操作：员工对照职级标准模型，录入申报信息，提交申报
- 说明：员工可通过自助门户，对照职级标准模型，便捷录入申报信息，包括个人基本信息、履职表现、能力素质、业绩成果等。支持员工自助申报及流程跟进。HR也可代为发起申报。

### 5. 资料复核

- 负责人：HR/HRBP
- 操作：对申报材料进行复核，确认信息真实性和完整性
- 说明：对员工申报的材料进行复核，确认信息的真实性和完整性。复核内容包括基本信息、履职表现、能力素质举证、业绩成果等。复核通过后进入评审安排环节。

### 6. 评审安排

- 负责人：人才发展专员/HR
- 操作：安排评委、确定评审方式、创建评审活动
- 说明：根据评定计划，安排评委、确定评审方式（会议评审、在线评审、答辩评审等）、创建评审活动。支持多种评审方式，可根据职等层级选择不同的评审形式。

### 7. 评审评议

- 负责人：评委
- 操作：查看员工申报信息，填写评议意见，给出评议结果
- 说明：评委可查看员工申报信息，同时便捷填写评价。支持多位评委针对员工能力细项逐项评估并给出认证结论。支持举证信息切换速览，辅助评委高效评议。

### 8. 结果决议

- 负责人：决议评委/HR
- 操作：汇总评议结果，决议最终评定结果
- 说明：汇总多位评委的评议结果，由决议评委确定最终评定结果。支持通过、不通过、待定等决议结果。决议结果作为职级调整的依据。

### 9. 结果报批

- 负责人：审批领导
- 操作：报批评定结果，审批通过
- 说明：将评定结果报批至审批领导，完成多级审批流程。审批通过后，评定结果正式生效。

### 10. 结果应用

- 负责人：HR/员工
- 操作：评定结果应用于职级调整、薪酬调整、人才发展
- 说明：员工完成职级评定后，如评定结果为晋升，则会在人员档案增加一条晋升的职级职等调整记录。评定结果可作为薪酬调整、人才发展的重要依据。

## 参与角色

| 角色 | 职责 |
|------|------|
| 人才发展专员 | 建立职级标准、创建评定计划、统筹评定流程、安排评审 |
| HR/HRBP | 资料复核、评审安排、结果报批、代为申报 |
| 部门负责人 | 晋升提名、提供推荐意见 |
| 员工 | 自助申报、查看流程进展 |
| 评委 | 评审评议、给出评议结论 |
| 决议评委 | 汇总评议结果、决议最终结果 |
| 审批领导 | 审批评定结果 |

## 基础配置要素

- 职级标准（职位、职等、素质要求）
- 申请资格（常规通道、绿色通道）
- 评议形式（会议评审、在线评审、答辩评审等）
- 评定计划模板
- 申报单模板
- 评审活动模板
- 审批流程配置

## 与其他应用的关联

| 关联应用 | 关联内容 |
|----------|----------|
| 核心人力云 | 评定结果为晋升时，更新人员档案的职级职等 |
| 能力素质模型 | 职级标准引用能力素质模型 |
| 任职资格 | 任职资格结果可作为评定参考 |
| 目标绩效云 | 绩效结果可作为评定参考 |
| 人才盘点 | 盘点结果可作为晋升提名参考 |
