# 订单处理流程

## 流程概述

订单从创建到完成经历以下阶段：

创建订单 → 支付确认 → 审核 → 备货 → 发货 → 签收 → 完成

## 详细步骤

### 1. 创建订单

用户在前台选择商品、填写收货信息后提交订单，系统生成订单号。

### 2. 支付确认

用户完成支付后，支付系统回调确认，订单状态变为"已支付"。超过30分钟未支付则自动取消。

### 3. 订单审核

金额超过5000元的订单需经主管审批。审批通过后进入备货环节。

### 4. 备货与发货

仓库根据订单信息拣货、打包，交由物流公司发货。发货后系统自动发送物流单号通知用户。

### 5. 签收与完成

用户签收后订单状态变为"已完成"。签收后7天内可申请售后。

## 异常处理

- 库存不足：通知用户并可选择等待补货或退款
- 支付失败：引导重新支付，保留订单30分钟
- 物流异常：客服介入处理，必要时补发
