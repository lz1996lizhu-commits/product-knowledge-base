# 人才盘点全流程

## 流程概述

人才盘点是基于企业战略目标，通过系统化的盘点活动推动：盘清人才布局、搭建人才梯队、挖掘高潜人才。支持企业面向干部、高潜等多类型人才进行盘点业务推进，覆盖从盘点计划建立到结果应用的完整生命周期。

## 流程阶段

盘点计划建立 → 盘点活动创建 → 盘点对象分组 → 盘点过程跟进 → 盘点结果校准 → 结果应用

## 详细步骤

### 1. 盘点计划建立

- 负责人：人才发展专员
- 操作：建立盘点计划，设置计划基本信息、起止日期、盘点目的和要求
- 说明：基于企业人才结构、数量和能力现状，从管理需求出发，面向全员/干部/特定人群制定某个周期内的盘点计划。计划启动后可跟进当前计划下的盘点活动进展，辅助统筹执行盘点跟踪、推进、及关键信息留痕。

### 2. 盘点活动创建

- 负责人：人才发展专员/HRBP
- 操作：创建盘点活动，配置活动基本信息、盘点维度、宫格配置
- 创建方式：
  - 基于盘点计划创建活动（常态化盘点）
  - 灵活发起盘点（非常态化盘点，如摸底任用活动）
- 说明：支持基于计划建立多个盘点活动，并进行分组盘点。活动基本信息包括活动名称、适用层级、盘点类型等。盘点标准制定包括盘点适用人员范围、盘点维度选定、盘点工具选定、宫格配置。

### 3. 盘点对象分组

- 负责人：人才发展专员/HRBP
- 操作：添加盘点对象，创建盘点组，指定盘点协作人
- 说明：在活动下按需建立盘点组，并指定盘点协作人。管理用户全局把控活动进展，整体分组规划及协作分配、所有盘点对象盘点进度及过程数据收集情况、校准会推进情况。协作用户跟踪数据范围内人员进展，所见即所得的进行权限范围内人员跟踪及校准。

### 4. 盘点过程跟进

- 负责人：盘点协作人/HRBP
- 操作：跟进或录入盘点结果，收集过程数据
- 说明：可以跟进或录入盘点结果，收集盘点对象的过程数据。支持多维度评估，包括绩效、能力、潜力、价值观等。

### 5. 盘点结果校准

- 负责人：人才发展专员/部门负责人
- 操作：在线拖拽校准，实时备注校准原因，查看校准前后分布
- 说明：多种校准方式，实时数据统计，辅助校准会高效进展。便捷拖拽校准，基于实时讨论结果快速调整人员落位，可视化了解实时分布辅助决策。实时备注校准原因，便捷追溯过程校准原因及有效进行关键信息留痕。实时反馈校准前后比例分布及建议分布比例，实时获悉校准进展。

### 6. 结果应用

- 负责人：人才发展专员/HRBP
- 操作：将盘点结果应用于人才储备池、继任梯队、培训计划
- 说明：基于校准结果，同步推荐盘点对象至储备池、至继任梯队。盘点结果可作为人才发展、晋升、培养的重要依据。

## 参与角色

| 角色 | 职责 |
|------|------|
| 人才发展专员 | 建立盘点计划、创建盘点活动、统筹盘点进展、校准管理 |
| HRBP | 创建盘点活动、盘点协作、过程跟进、校准参与 |
| 盘点协作人 | 盘点数据准备、活动跟踪、过程数据收集、校准参与 |
| 部门负责人 | 校准会参与、结果确认 |

## 基础配置要素

- 盘点类型（系统预置+自定义）
- 盘点适用层级（系统预置+自定义）
- 终止盘点原因（系统预置+自定义）
- 盘点活动模板
- 评估项与盘点维度评估方案
- 宫格配置（九宫格、十二宫格等）

## 与其他应用的关联

| 关联应用 | 关联内容 |
|----------|----------|
| 人才储备池 | 盘点结果可推荐至储备池 |
| 继任计划 | 盘点结果可推荐至继任梯队 |
| 目标绩效云 | 绩效结果可作为盘点维度 |
| 任职资格 | 任职资格结果可作为盘点参考 |
