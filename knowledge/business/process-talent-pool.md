# 人才储备池全流程

## 流程概述

人才储备池旨在为企业建立系统化、规范化的人才储备与培养机制，提供从"建池"到"出池"的全生命周期管理能力。支持分层分类搭建人才储备体系，通过多渠道发掘人才、差异化流程审批、定向培养，保障企业人才供给，加强人才梯队建设。

## 流程阶段

储备池建立 → 人才推荐与受理 → 入池审批 → 储备人才培养 → 出池评估 → 出池审批 → 人才任用

## 详细步骤

### 1. 储备池建立

- 负责人：人才发展专员
- 操作：创建人才储备池，设定储备池适用范围、人数限制、入池/出池标准
- 说明：根据企业战略和用人需求，灵活创建并维护人才储备池。通过设定储备池适用范围以及人数限制，确保可面向核心组织、关键群体提供发展资源。清晰定义入池和出池的标准，确保人才储备的质量和适用性。支持分层分类的储备池建设，如高管储备池、中层储备池、高潜人才储备池等。

### 2. 人才推荐与受理

- 负责人：HRBP/直接主管/人才发展专员
- 操作：多渠道推荐人才，受理入池申请
- 推荐渠道：
  - 盘点结果推荐（盘点校准后同步推荐）
  - 直接主管推荐
  - HRBP推荐
  - 员工自主申请
- 说明：支持盘点结果推荐，以及直接主管、HRBP等角色的个性化推荐，构建多元化的人才发现渠道。推荐时需填写推荐理由、人才优势、发展潜力等信息。系统受理推荐后，进入入池审批流程。

### 3. 入池审批

- 负责人：审批领导/HR
- 操作：审核入池申请，审批入池
- 说明：对推荐人才进行审核，确认是否符合入池标准。支持差异化的流程审批，可根据储备池类型配置不同的审批流程。审批通过后，人才正式入池，系统记录入池时间、入池类型等信息。

### 4. 储备人才培养

- 负责人：HRBP/人才发展专员
- 操作：制定培养计划，跟进培养进展，记录培养事件
- 说明：为储备人才制定个性化培养计划，包括培训学习、轮岗锻炼、项目实践、导师辅导等。跟进培养进展，记录培养事件。提供全面视角的储备人才管理，帮助企业在人才管理上做出更明智的决策。关注人才结构，识别人才缺口，提供储备池、储备人才及储备人才平均情况的数据总览，提供精细化的储备人才结构化分析（学历结构分布、胜任力分布等）。

### 5. 出池评估

- 负责人：HRBP/人才发展专员
- 操作：评估储备人才是否满足出池标准
- 说明：定期评估储备人才的成长情况，确认是否满足出池标准。出池标准包括能力达标、绩效达标、培养计划完成等。评估结果作为出池审批的依据。

### 6. 出池审批

- 负责人：审批领导/HR
- 操作：审核出池申请，审批出池
- 说明：对满足出池标准的人才进行出池审批。支持差异化的流程审批，可根据出池类型（晋升、调动、淘汰等）配置不同的审批流程。审批通过后，人才正式出池，系统记录出池时间、出池类型等信息。

### 7. 人才任用

- 负责人：HR/用人部门
- 操作：将出池人才任用至目标岗位
- 说明：出池人才可进入干部任免流程、内部招聘流程等，完成正式任用。任用后系统自动更新人员档案，保持人才发展记录的连续性。

## 参与角色

| 角色 | 职责 |
|------|------|
| 人才发展专员 | 建立储备池、统筹储备计划、跟进培养进展、出池评估 |
| HRBP | 推荐人才、跟进培养、提供推荐意见 |
| 直接主管 | 推荐人才、参与培养、提供反馈 |
| 储备人才 | 参与培养计划、提升能力 |
| 审批领导 | 审批入池/出池申请 |
| HR | 统筹入池/出池流程、人才任用 |

## 基础配置要素

- 储备池类型（高管储备、中层储备、高潜人才等）
- 入池标准（能力要求、绩效要求、资格要求等）
- 出池标准（能力达标、绩效达标、培养完成等）
- 入池类型（盘点推荐、主管推荐、自主申请等）
- 出池类型（晋升、调动、淘汰等）
- 入池/出池审批流程配置
- 培养计划模板

## 与其他应用的关联

| 关联应用 | 关联内容 |
|----------|----------|
| 人才盘点 | 盘点结果可推荐至储备池 |
| 继任计划 | 储备池人才可推荐至继任梯队 |
| 干部管理 | 出池人才可进入干部任免流程 |
| 内部招聘 | 出池人才可参与内部招聘 |
| 任职资格 | 任职资格结果可作为入池/出池参考 |
| 核心人力云 | 人才任用后更新人员档案 |
