# 任职资格认证流程

## 流程概述

任职资格认证是评估和确认员工在特定职位上是否具备所需资格标准的一系列步骤和程序，覆盖从认证计划建立到结果通知的全生命周期。

## 流程阶段

认证计划 → 认证申请 → 资格审查 → 认证考核 → 认证公示 → 结果通知 → 申诉复核

## 详细步骤

### 1. 认证计划

- 负责人：人才发展专员
- 操作：建立认证计划，设置标准范围、认证材料要求
- 说明：基于企业认证统一管理需要，HR可根据引导完成基本信息、周期、标准范围等设置。计划启动后可随时查看申请人次、通过率等执行情况。

### 2. 认证申请

- 负责人：员工/HRBP
- 操作：员工自主申请或HR代申请
- 说明：支持计划内申请和非计划申请两种模式。员工可通过自助门户发起申请，HR也可代为发起。流程启动后可实时跟踪进度。

### 3. 资格审查

- 负责人：HRBP/部门领导
- 操作：资格审核、材料审核
- 说明：对申请人的基本条件、材料完整性进行审核，确认是否满足认证前置条件。

### 4. 认证考核

- 负责人：评委/HRBP
- 操作：评委安排、考核打分、考核意见反馈、认证结果决议
- 说明：HR发起考核安排，选择评委与考核内容。多位评委可针对员工能力细项逐项评估并给出认证结论，最终由决议评委确定最终结果。支持举证信息切换速览。

### 5. 认证公示

- 负责人：HRBP
- 操作：发起公示、公示内容展示、公示结果确认
- 说明：HR自定义公示周期、范围与跟踪人。公示消息按模板触达指定人群，公示周期内可驳回或提前完成。

### 6. 结果通知

- 负责人：HRBP/员工
- 操作：通知员工认证结果
- 说明：认证完成后系统自动发送结果通知。

### 7. 申诉复核

- 负责人：员工/HRBP/部门领导
- 操作：员工申诉→申诉受理→意见征询→复核安排→复核打分→申诉结果决议
- 说明：员工对认证结果有异议可发起申诉，经申诉受理和意见征询后安排复核打分。

## 参与角色

| 角色 | 职责 |
|------|------|
| 人才发展专员 | 建立认证计划、设置标准范围 |
| HRBP | 代申请、资格审核、考核安排、公示管理 |
| 员工 | 自主申请、自评、查看结果、发起申诉 |
| 评委 | 考核打分、给出认证结论 |
| 部门领导 | 审核、意见征询 |

## 基础配置要素

- 专委会组织与能力素质模型
- 任职资格标准（基本条件、能力等级要求、有效期）
- 认证组管理
