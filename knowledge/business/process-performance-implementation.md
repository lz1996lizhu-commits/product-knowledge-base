# 目标绩效云交付实施配置指南

## 实施配置总体流程

目标绩效云的交付实施按照"设规则→定框架→配数据→控过程→查结果"的顺序推进，确保绩效管理体系从政策到执行完整落地。

## 第一步：设规则（目标绩效规则配置）

在绩效体系搭建之前，需要先完成基础规则的配置：

- **评分分制**：预置100分制、10分制、5分制等多种分制，支持客户自定义
- **等级标尺**：集团化公司下建立绩效等级对齐工具，实现不同分子公司等级统一对标
- **等级规则**：配置绩效等级与分制的映射关系、绩效等级与等级标尺的映射关系
- **正态分布规则**：配置绩效等级分布比例要求
- **角色类型**：预置员工本人、直接上级、间接上级等10种常见角色类型，支持自定义角色类型和定位逻辑

### 关键确认问题

依据企业业务架构体系和绩效业务政策管控体系，梳理以下问题：
1. 有哪些绩效政策需要配置？
2. 考核人员范围是什么？
3. 何时开始考核？何时停？何时要根据前端业务发生变化？

## 第二步：定框架（考核计划设置）

根据企业管理架构和绩效政策体系，搭建考核计划框架：

- **考核计划设置**：按周期、人群、政策、流程搭建考核计划，支持多周期组合（年+季、年+月等）
- **考核活动设置**：在考核计划下创建具体考核活动，配置评估对象分组、考核模板/表单、考核流程、权限等

### 关键确认问题

1. 企业业务架构体系和绩效业务政策管控体系是怎样的？
2. 考核周期是怎样的（年度、半年、季度、月度）？
3. 有哪些考核场景？每个绩效组织用什么方式考核？
4. 不同组织考核表单有什么差异？考核流程的活动有哪些？
5. 指标制定流程和评估流程分别是什么？是否存在交叉评分场景？

## 第三步：配数据（数据初始化与表单流程）

### 3.1 绩效档案初始化

- 支持快速导入个人绩效档案
- 灵活按任职建档考核（主任职、兼职、借调可分别建档）

### 3.2 评估表单管理

- 配置评估表单，支持KPI/BSC/PBC等多种考核模式的表单
- 配置评估表区域（指标区、加减分区、总评区等）
- 配置字段及评分规则（得分计算方式、保留小数位数、超分限制等）

### 3.3 考核流程设置

- 配置绩效流程（支持活动环节配置、子流程、手动/自动获取评估人）
- 支持多节点指标制定流程配置
- 支持灵活配置多任务类型的绩效评估流程
- 支持简易工作流配置（一个节点下创建多个角色，串并行灵活配置）

## 第四步：控过程（考核活动执行过程管理）

考核活动启动后，HR需要对全过程进行监控和管理：

- **指标制定管理**：监控指标制定进度，支持催办、退回、调整制定人
- **绩效评估管理**：监控评估进度，支持评估人设置/调整/催办/退回
- **评估对象管理**：添加/删除评估对象，考核进度回退
- **流程调整**：支持增删减改考核活动内指标制定/绩效评估流程
- **权限调整**：灵活调整各环节权限设置

## 第五步：查结果（绩效结果查看）

- 绩效结果明细列表查看
- 多维度、多方式的绩效校准
- 可自定义、多场景的结果汇总
- 绩效面谈与改进计划

## 实施落地关键梳理维度

在实施过程中，需要从以下六个维度进行系统梳理：

| 维度 | 关键问题 |
|------|----------|
| 考核谁 | 企业业务架构和绩效政策管控体系下有哪些绩效政策？考核人员范围？ |
| 何时考 | 何时开始考核？何时停？何时要根据前端业务变化调整？ |
| 怎么考 | 有哪些考核场景？每个组织用什么方式考核？表单差异？流程活动？ |
| 定框架 | 业务架构体系和政策管控体系？考核周期？ |
| 控过程 | 如何派发指标？如何进行考核过程监控？ |
| 怎么查 | 如何查看绩效结果？ |
