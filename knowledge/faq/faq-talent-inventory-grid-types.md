# 人才盘点宫格配置是否支持12宫格？

## 问题描述

人才盘点中的宫格配置是否支持12宫格？当前系统支持的宫格类型有哪些？

## 解答

**不支持12宫格。**

当前人才盘点的宫格配置仅支持以下五种宫格类型：

| 宫格类型 | 说明 |
|---------|------|
| 九宫格 | 3×3 矩阵，共9个格子 |
| 四宫格 | 2×2 矩阵，共4个格子 |
| 十六宫格 | 4×4 矩阵，共16个格子 |
| 横向六宫格 | 3×2 矩阵，共6个格子 |
| 纵向六宫格 | 2×3 矩阵，共6个格子 |
