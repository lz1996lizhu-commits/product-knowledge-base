# 如何重置密码

## 问题描述

用户忘记密码或需要更换密码时，如何操作？

## 解决方案

### 方式一：通过邮箱重置

1. 进入登录页，点击"忘记密码"
2. 输入注册邮箱
3. 查收重置邮件（有效期15分钟）
4. 点击邮件中的链接设置新密码

### 方式二：通过手机验证码重置

1. 进入登录页，点击"忘记密码"
2. 选择"手机验证"
3. 输入注册手机号并获取验证码
4. 输入验证码后设置新密码

### 方式三：联系管理员

如果邮箱和手机号都无法使用，联系系统管理员通过后台重置。

## 密码要求

- 长度：8-20位
- 必须包含：大写字母、小写字母、数字中的至少两种
- 不能与最近3次使用的密码相同
