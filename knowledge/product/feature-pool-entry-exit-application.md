# 出入池申请

## 功能介绍

支持对储备人才的入池和出池进行管理，并提供差异化的流程审批，确保人才流动性和储备池的活力。

## 应用场景

人才推荐完成后，系统自动生成入池申请单，HR专员对申请单进行审核，确认人才信息和入池条件后完成入池操作；当储备人才因晋升或培养期满需退出时，发起出池申请。

## 系统路径

人才发展云 > 人才储备池 > 出入池管理 > 出入池申请列表

## 主要操作

### 入池申请单

![入池申请单](../images/product/0100e871d97595c64c85be4043c4cdeabeea.png)

![入池申请详情](../images/product/01006f19b61169a14182a4bdf0e73df69118.png)

#### 关键字段说明

| 字段名称 | 详细解释 |
| --- | --- |
| 入池类型 | 用于发起入池申请单时标识人才进入储备池的来源方式，如"业务部门推荐"、"人才盘点推荐"等 |
| 储备目标胜任力 | 员工在储备目标岗位上的胜任力评估结果，如：胜任、基本胜任、暂不胜任 |
| 当前岗位胜任力 | 员工在当前岗位上的胜任力评估结果，如：胜任、基本胜任、暂不胜任 |

#### 操作校验说明

1. 拟入池员工必须处于在职状态，且未在拟入储备池中处于"在池"状态；
2. 入池日期不可早于储备池的生效日期；
3. 若拟入储备池开启了人数限制，入池审核时将校验剩余可入池人数。
