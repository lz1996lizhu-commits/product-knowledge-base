## 盘点活动：在线校准

**1 功能介绍**

支持创建校准会，对盘点对象的盘点落位进行拖拽校准、校准原因维护、实时查看校准前后宫格比例分布。

**2 应用场景**

校准是人才盘点业务中的关键环节，用于对初步评估结果进行集体讨论、审核和调整。通过校准会，HR 和组织管理者可以对盘点对象的评估结果进行多维度校准，确保人才盘点结果的客观性和准确性。校准功能支持在线校准、校准历史记录查看、校准比例分析等，帮助企业实现科学的人才评估决策。

**3 系统路径**

人才发展云>人才盘点>盘点活动>我管理的>盘点活动列表/详情页>校准会

**4.1.1 关键字段说明**

| 字段名称 | 详细解释 |
| --- | --- |
| 组织者 | 只有校准会的组织者才可以维护该条校准会数据，并开启在线校准。 |
| 人员位置调整后，校准原因是否必填 | 设置在线校准过程中，改变盘点对象的落位后，是否必须填写校准原因。 |
| 校准原因填写方式 | 每次拖拽实时填写：在线校准中，每次拖拽人员进行校准后，实时出现校准原因填写弹窗；拖拽后统一填写：在线校准中，每次拖拽人员进行校准后，不出现校准原因填写弹窗，可在右侧"校准人员"工具栏中统一填写校准原因。 |

**4.2 在线校准**

**4.2.1 页面构成说明**

| 页面内容 | 说明 |
| --- | --- |
| 列表视图 | 通过列表，结构化展示员工信息。 |
| 宫格视图 | 通过宫格，展示员工落位分布，可拖拽调整落位。 |
| 导航视图 | 聚焦展示某个宫格的员工，可拖拽调整落位。 |
| 过滤 | 过滤面板，通过盘点状态过滤盘点对象后，可在不同视图查看。 |
| 已校准人员 | 已校准人员面板，查看宫格落位发生过变化的盘点对象。 |
| 校准看板 | 查看宫格中每个格子的人员分布变化情况。 |
