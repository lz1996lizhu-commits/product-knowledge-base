# 目标绩效云

- 【功能优化】优化了结果确认页面未展示汇总信息的问题，提升了用户在操作后对整体数据的可读性和业务闭环体验
- 【功能优化】优化了系统参数配置体系，下架旧参数EPA_ISOPENREFINDICATORLIB以推进新架构标准化建设。注意：请检查现有配置中是否引用该参数，如有需及时调整配置或联系技术支持
- 【功能优化】优化了员工变动处理中的信息变更生效机制，支持批量生效处理，提升人事事务变动场景下的绩效数据适配效率
- 【问题修复】修复了考核计划在引用评估流程后仍可修改的问题，修复后将变为仅可查看不可修改，确保业务流程的严谨性
- 【问题修复】修复了绩效评估保存后提交报错的问题
