## 盘点活动：创建活动

**1 功能介绍**

盘点活动是人才盘点模块中实际执行盘点工作的核心功能单元，而"基本信息"是盘点活动的第一个配置步骤。通过基本信息页面，HR可以设定盘点活动的核心属性，包括盘点组织范围、盘点内容、人员范围以及宫格配置等关键要素。

**2 应用场景**

在企业开展人才盘点时，通常会基于盘点类型、业务组织、行政组织将盘点计划拆解为盘点活动，开展盘点事务并跟进盘点过程。通过维护盘点活动的基本信息，定义一次盘点活动，规定当次盘点所遵循的规则。

**3 系统路径**

人才发展云>人才盘点>盘点活动>我管理的>盘点活动详情页

**4.1.1 关键字段说明**

| 字段名称 | 详细解释 |
| --- | --- |
| 盘点活动模板 | 企业基于盘点政策要求制定通用盘点活动模板，包含：方案适用盘点类型、适用工具，是否允许引用方案活动调整工具等信息；方便在创建盘点活动时快速引用。 |
| 所属行政组织 | 明确盘点活动归属于哪个行政组织管理，用于活动列表的数据权限控制。 |
| 适用行政组织 | 框定盘点活动中可以盘点哪些行政组织的员工，用于添加盘点对象时的数据过滤。 |
| 盘点内容 | 明确本次盘点需要从哪些维度对盘点对象进行评估；在宫格配置中，定义横纵轴维度及其他维度时，只能在配置的盘点维度中做选择。 |
| 盘点人员范围配置 | 根据盘点制度要求，明确本次盘点的人员基准范围（比如基于职级、员工类型框定范围）；后续明确盘点对象名单时，不能超过配置的人员范围。 |
| 宫格配置 | 明确盘点时使用的宫格（宫格类型、宫格样式、横纵轴维度及划线标准、其他维度、宫格建议比例），在后续校准会中，可选择此处配置的宫格推进校准工作。 |

**4.1.2 异常提示及处理**

| **提示内容** | **处理方式** |
| --- | --- |
| 活动关联活动模板后，活动模板内容被调整了 | 盘点活动-盘点活动模板字段后侧将出现"获取活动模板最新配置"按钮，点击可重新获取活动模板内容。 |
| 根据盘点人员范围生成了盘点对象名单后，又调整了盘点人员范围 | 点击盘点人员范围分录右上角的"获取范围下人员"按钮，按照新的范围重新获取。 |
