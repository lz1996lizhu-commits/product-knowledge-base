# 储备池管理

## 功能介绍

支撑企业根据战略规划与用人需求，灵活创建并维护人才储备池，通过设定储备池适用范围及人数限制，确保面向核心组织、关键群体提供可发展资源。

## 应用场景

企业需要围绕中高层经营管理人才、核心专业人才等群体建立专属储备机制时，由HR专员创建储备池，设定培养目标、适用行政组织和人数上限，为后续人才推荐与入池奠定管理基础。

#### 关键字段说明

| 字段名称 | 详细解释 |
| --- | --- |
| 所属行政组织 | 用于人才储备池编辑权限的控制，即在人才储备池列表，用户只能编辑所属行政组织相匹配的人才储备池。 |
| 储备池类型 | 区分储备池所面向的人才群体，如经营管理类、专业技术类等。 |
| 适用行政组织 | 用于人才储备池使用权限的控制，即在人才推荐、入池申请时，用户只能选择到适用行政组织相匹配的人才储备池。 |

#### 操作校验说明

- "适用行政组织"至少需添加一条记录，否则无法保存储备池。
