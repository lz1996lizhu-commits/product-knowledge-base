人才档案批量创建和批量失效功能支持按条件或者直接选择员工，对符合条件的员工进行批量档案创建或失效操作。

批量创建人才档案：过滤出符合条件的员工的任职经历，基于任职经历创建人才档案。

批量失效人才档案：过滤出符合条件的人才档案并失效。

# 2 应用场景

当企业需要批量管理人才档案时，在以下场景适用该功能：

*   历史数据补录：系统上线初期，需要对当前在职员工批量创建人才档案
    
*   新员工批量建档：企业新入职一批员工，需要为他们批量创建人才档案
    
*   组织架构调整：因组织架构调整，需要批量失效部分人才档案
    
*   员工离职处理：批量处理离职员工的人才档案失效
    

企业也可以通过订阅员工变动消息和员工协作配置功能实现人才档案自动创建/更新/失效，想了解更多可查看文章[《人才档案-员工变动及处理》](https://vip.kingdee.com/knowledge/829749390024524032)。

# 3 系统路径

**人才发展云 > 人才档案 > 人才档案**

# 4 主要操作

## 4.1 批量创建人才档案

### 4.1.1 操作应用场景

当需要为多名员工批量创建人才档案时，可使用批量创建功能。支持两种筛选方式：按条件筛选或直接选择员工。

### 4.1.2 操作步骤

**第一步：筛选**

1.  在人才档案列表页面，点击【批量生效】按钮，打开批量创建弹窗。
    
2.  选择筛选方式：
    
    **选条件**：通过设置筛选条件过滤员工，包括用工关系类型、用工关系状态、行政组织、岗位、职位、职位序列、职位族、职位类、职级、职等
    
    **选人**：直接选择指定员工
    
3.  如选择"选条件"方式，至少选择一个筛选条件，常见场景如：
    
    1）企业对全员做人才管理，则可选用工关系状态为在职，即可快速筛选出当前在职且未创建人才档案的员工信息；
    
    2）企业仅对干部做人才管理，则可通过岗位、职位、职位序列、职级、职等等条件进行筛选。
    
4.  如选择"选人"方式，在员工F7中选择需要创建档案的员工。
    

![上传图片](../images/images/0100ade695abaaf749b79af21b3684bae954.png)

**第二步：确认名单并创建档案**

1.  系统展示筛选结果，分为两个页签：
    
    **待执行人员名单**：展示条件匹配的员工的生效中任职经历，且该任职经历对应的人才档案不存在或已失效
    
    **不满足条件人员名单**：展示条件匹配的员工的生效中任职经历，但该任职经历对应的人才档案已生效，或许可余额不足以为所有条件匹配的员工创建档案
    
2.  查看待执行列表，确认无误需要创建档案的人员信息。
    
3.  点击【导出全部】按钮可导出待执行和不满足条件的人员名单。
    
4.  确认无误后，点击【创建档案】按钮，系统将按待执行列表批量创建人才档案。
    

![上传图片](../images/images/010060b3fedc1f3a409ca367af4c98591ba4.png)

### 4.1.3 关键字段说明

筛选条件字段说明：

| **字段名称** | **说明** |
| --- | --- |
| 用工关系类型 | 员工的用工关系类型，如正式、实习生、劳务派遣等 |
| 用工关系状态 | 员工的用工关系状态，如在职、试用期等，默认仅在职-试用中、在职可选，如需扩展可通过开发平台调整F7的默认过滤条件 |
| 行政组织 | 员工任职部门 |
| 岗位 | 员工任职岗位 |
| 职位 | 员工职级职等中的职位 |
| 职位序列 | 员工职级职等中的所属职位序列 |
| 职位族 | 员工职级职等中的所属职位族 |
| 职位类 | 员工职级职等中的所属职位类 |
| 职级 | 员工职级职等中的职级 |
| 职等 | 员工职级职等中的职等 |

确认页面字段说明：

| **字段名称** | **说明** |
| --- | --- |
| 姓名 | 员工姓名 |
| 工号 | 员工工号 |
| 公司 | 员工任职公司 |
| 部门 | 员工任职部门 |
| 岗位 | 员工任职岗位 |
| 职位 | 员工任职职位 |
| 人才管理组织 | 默认员工任职部门对应的人才管理组织（员工管理关系策略），如需调整可创建档案后在档案详情页修改管理关系 |
| 管理部门 | 默认员工任职部门，如需调整可创建档案后在档案详情页修改管理关系 |
| 人才档案分组 | 默认人才档案分组 |
| 生效日期 | 默认任职经历开始日期 |
| 不执行原因 | 不满足条件的原因，如"管理关系已生效"或许可不足提示。 |

### 4.1.4 操作校验说明

筛选条件校验：如选择"选条件"方式，至少需选择一个筛选条件，否则系统会提示"至少选择一个条件"。

重复创建校验：同一任职经历不能重复创建人才档案，任职经历已有生效人才档案会显示在不满足条件列表中。

许可校验：创建档案时需要检查许可余额，许可不足时会显示在不满足条件列表中。

### 4.1.5 异常提示及处理

| **异常提示** | **处理方法** |
| --- | --- |
| 至少选择一个条件 | 在筛选页面至少选择一个筛选条件后再点击过滤按钮 |
| 管理关系已生效 | 该任职经历已创建人才档案且状态为生效，无需重复创建 |
| 许可不足 | 请联系系统管理员增加许可数量，或先批量失效部分人才档案以释放许可 |

## 4.2 批量失效人才档案

### 4.2.1 操作应用场景

当需要批量失效人才档案时，可使用批量失效功能。适用于员工离职、组织架构调整等场景。

### 4.2.2 操作步骤

**第一步：筛选**

1.  在人才档案列表页面，点击【批量失效】按钮，打开批量失效弹窗。
    
2.  选择筛选方式：
    
    **选条件**：通过设置筛选条件过滤人才档案，包括用工关系类型、用工关系状态、行政组织、岗位、职位、职位序列、职位族、职位类、职级、职等
    
    **选人**：直接选择指定员工的人才档案
    
3.  如选择"选条件"方式，至少选择一个筛选条件，常见场景如：企业定期失效离职员工人才档案，则可选用工关系状态为离职，即可快速筛选出当前离职且生效中人才档案的员工信息
    
4.  如选择"选人"方式，在员工F7中选择需要失效档案的员工。
    

![上传图片](../images/images/0100d83aaba037b1413bb8a04bfc53570886.png)

**第二步：确认名单并失效档案**

1.  系统展示筛选结果，分为两个页签：
    
2.  **待执行人员名单**：展示条件匹配的人才档案数据，且其状态为生效
    
    **不满足条件人员名单**：展示条件匹配的人才档案数据，但其状态已为失效或不存在
    
3.  查看待执行列表，确认需要失效的档案信息。
    
4.  点击【导出全部】按钮可导出待执行和不满足条件的档案清单。
    
5.  确认无误后，点击【失效档案】按钮，系统将按待执行列表中的档案批量执行失效操作。
    

![上传图片](../images/images/0100544bc2c5c8f249c79fba52de09a32541.png)

| 行政组织 | 人才档案关联的行政组织 |
| 岗位 | 人才档案关联的任职岗位 |
| 职位 | 人才档案关联的职位 |
| 职位序列 | 人才档案关联的职位序列 |
| 职位族 | 人才档案关联的职位族 |
| 职位类 | 人才档案关联的职位类 |

### 4.2.4 操作校验说明

状态校验：仅允许失效状态为生效的人才档案。

重复失效校验：已失效的人才档案会显示在不满足条件列表中，提示"管理关系已失效"。

### 4.2.5 异常提示及处理

| 管理关系已失效 | 该人才档案状态已为失效，无需重复失效 |

# 5 常见问题

**Q1：批量创建和批量失效有什么区别？**

A：批量创建是基于员工当前在任的任职经历创建新的人才档案；批量失效是将已生效的人才档案置为失效状态。

**Q2：为什么有些员工在"不满足条件"列表中？**

A：批量创建时，如果员工的任职经历已创建过人才档案且状态为生效，或许可余额不足，会显示在不满足条件列表。批量失效时，如果人才档案状态已为失效，也会显示在不满足条件列表。

**Q3：可以导出待处理的人员清单吗？**

A：可以。在第二步确认页面，点击【导出全部】按钮，可以导出待生效/待失效和不满足条件的人员清单。

**Q4：筛选条件之间是什么关系？**

A：多个筛选条件之间是"且"的关系，即需要同时满足所有条件才会被筛选出来。
