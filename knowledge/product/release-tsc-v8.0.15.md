# 内部招聘

- 【功能优化】优化了面试评价表配置及面试评价功能，提升用户体验
- 【功能优化】优化了应聘进展展示功能，提升用户体验
- 【功能优化】优化了内部招聘中取消面试功能的逻辑处理，提升了面试流程操作的稳定性和用户体验
- 【功能优化】优化了内部招聘中我要应聘功能的适用员工范围配置能力，通过架构调整提升了配置灵活性和系统可维护性
- 【功能优化】优化了内部招聘中招聘职位与广告修改操作的提示信息，提升用户操作反馈的清晰度与准确性
- 【功能优化】优化了内部招聘中招聘职位、广告、录用工作流的模板预置能力，基于新架构解决历史遗留配置繁琐问题，提升招聘流程创建效率
- 【功能优化】优化了广告关联审批单据唯一时删除单据的处理逻辑，支持同步删除对应的基础资料，避免产生冗余数据，提升数据一致性
- 【功能优化】优化了我要应聘首页的页面展示效果，隐藏了政策公告区块并修复快速入口白色背景未拉伸到底部的遗留问题，提升界面整体视觉一致性
- 【功能优化】优化了内部招聘新架构下面试日历的遗留问题处理能力，提升了日历数据展示的准确性和功能稳定性
- 【功能优化】优化了广告申请单提交时的流程校验机制，提交时将校验是否匹配到对应工作流，确保流程发起的合规性
- 【功能优化】优化了广告申请单在"暂存"状态下的操作体验，详情页新增"删除"按钮，便于用户快速清理无效暂存单据
- 【功能优化】优化了内部招聘场景下职位基础资料与相关单据的联动机制，提升数据一致性与流程协同效率
- 【功能优化】优化了内部招聘模块中权限树的显示逻辑，解决了架构优化过程中遗留的权限节点展示不清晰问题，提升用户配置权限时的可读性与操作效率
- 【功能优化】优化了内部招聘模块中与架构优化相关的遗留功能，完善了预置权限维度的控制逻辑，提升系统权限管理的清晰度与可维护性
- 【功能优化】优化了内部招聘中推荐筛选和安排面试通知的链接名称，提升通知中链接名的可读性与用户操作体验
- 【功能优化】优化了内部招聘录用申请单中查看候选人按钮的交互逻辑，提升用户操作效率与页面响应一致性
- 【功能优化】优化了内部招聘场景下招聘原因基础资料功能的架构设计，解决了遗留功能的技术债务，提升了系统的稳定性和可维护性
- 【功能优化】优化了广告申请单操作按钮的展示逻辑与交互体验，提升了页面操作的一致性与用户使用效率
- 【功能优化】优化了内部招聘场景下候选人锁定功能的架构设计，解决了遗留功能的技术债务，提升了系统稳定性和功能可维护性
- 【功能优化】优化了内部招聘中筛选、笔试、面试环节的消息通知机制，通过架构优化解决了遗留功能的通知延迟与重复问题，提升了招聘流程中关键节点消息的及时性与准确性
- 【功能优化】优化了内部招聘模块中管理人字段的架构设计，提升了字段的可维护性与系统兼容性，支持后续业务扩展
- 【功能优化】优化了内部招聘中筛选、笔试、面试环节的消息通知渠道，提升了消息触达的稳定性与系统架构的可维护性
- 【功能优化】优化了AI功能的系统架构，将原有遗留功能迁移至新架构，提升了系统的稳定性与可维护性
- 【功能优化】优化了内部招聘架构中录用环节的候选人信息校验逻辑，删除了转移至录用环节时对手机、邮箱必填性校验的冗余控制，提升流程灵活性
- 【功能优化】优化了招聘职位列表的字段展示逻辑，修复了因架构遗留问题导致的字段重复显示问题，提升了列表数据的准确性和界面整洁度
- 【功能优化】优化了招聘职位列表的广告状态显示逻辑，发布广告状态数据为0的职位不再展示，提升列表信息的准确性和用户浏览效率
- 【功能优化】优化了批量安排面试时对手机、邮箱为空的校验逻辑，由原强制校验调整为条件性校验，提升操作灵活性并更好兼容历史数据场景
- 【功能优化】优化了审批通过或免审批的录用申请单废弃后人事变动状态未正确回滚的问题，确保业务状态与实际流程保持一致
- 【功能优化】优化了内部招聘场景下消息模板的HTML拼接逻辑，解决了因特殊字符或标签嵌套导致的格式错乱问题，提升消息内容渲染的稳定性与一致性
- 【功能优化】优化了内部招聘及招聘服务直通车中年龄要求与工作年限要求的录入交互与显示逻辑，提升用户填写体验及信息展示准确性
- 【功能优化】优化了内部招聘发送邮件消息时附件面板未显示的问题，解决了该功能在架构调整过程中遗留的附件功能缺失问题
- 【功能优化】优化了内部招聘应聘流程的架构设计，解决了历史遗留问题，将我要应聘功能成功发布至HR智能助手，提升招聘场景的智能化交互体验
- 【功能优化】优化了审批单据驳回后消息通知页面不跳转的问题，提升用户从消息中心进入单据详情的链路畅通性
- 【功能优化】优化了内部招聘面试地址字段的填写规则，将面试地址由必填调整为非必填，提升招聘流程的灵活性和用户填写体验
- 【功能优化】优化了内部招聘中应聘许可及内招适用员工范围的判定逻辑，提升规则匹配的准确性与系统架构的可扩展性
- 【功能优化】优化了内部招聘候选人列表，增加了候选人解锁按钮，便于招聘人员快速操作解锁状态，提升招聘流程处理效率
- 【功能优化】优化了招聘职位和候选人实体的管理人字段，提升了数据结构的统一性与系统可维护性
- 【功能优化】优化了安排面试实体结构增加字段并完成历史数据升级，提升内部招聘场景下面试安排信息的完整性和可扩展性

# 招聘服务直通车

- 【功能优化】优化了简历附件下载地址长度，增加超长截取，提升系统稳定性
- 【功能优化】优化了Offer申请提交时，候选人手机和邮箱的必填校验，提升系统稳定性
- 【功能优化】优化了Moka操作人与星瀚平台用户的匹配逻辑，提升系统稳定性
- 【功能优化】优化了录用申请和候选人简历相关字段，并支持薪资标准匹配功能，提升招聘流程中候选人信息管理的规范性与薪酬匹配效率
- 【功能优化】优化了招聘服务直通车中教育经历和项目经历的开始/结束日期及至今选项的交互逻辑，提升候选人填写体验并增强时间数据的规范性与一致性
- 【功能优化】优化了元数据类型，解决了工作台卡片无法删除的问题
- 【功能优化】优化了招聘服务直通车在新架构下的多租户链接配置与验证机制，提升了配置灵活性和链接安全性
- 【功能优化】优化了候选人详情中录用申请、录用通知、入职协同的修改人和修改时间更新逻辑，仅在单据内容发生修改时更新，不随审批流程操作而变更
- 【功能优化】优化了招聘服务直通车及内部招聘模块中权限维度的映射逻辑，提升架构一致性与权限控制的精准度
- 【功能优化】优化了招聘服务直通车中发起入职流程，支持薪酬定薪内容对接到入职环节，提升入职流程中薪酬信息传递的完整性与处理效率
- 【功能优化】优化了招聘服务直通车中招聘职位与候选人相关接口的性能和稳定性，解决了新架构下的遗留问题，提升数据交互效率
- 【功能优化】优化了简历附件下载地址的处理逻辑，增加对超长地址的截取功能，提升系统稳定性
- 【功能优化】优化了候选人服务流程的架构设计，支持二次开发扩展，提升了招聘服务直通车在多样化业务场景下的流程灵活性和可扩展性。注意：二开实现时需确保自定义逻辑与主流程状态机兼容，避免流程节点冲突
