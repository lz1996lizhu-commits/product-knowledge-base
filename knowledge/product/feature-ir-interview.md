# 面试（内部招聘）

# 总体介绍

## 1 功能介绍

面试管理支持招聘专员对候选人面试全流程进行统筹管控，涵盖面试信息查看管理、面试安排调整、面试评价填写、相关状态更新等操作，实现招聘面试环节的规范化、高效化推进。

## 2 应用场景

当企业开展招聘工作，需对候选人的面试事宜进行统一管理时，可通过该功能实现相关操作。无论是查看候选人面试进度、调整面试时间地点，还是收集面试官评价、确认候选人答复情况，都能通过该功能完成，适配从面试筹备到结果确认的全场景需求。

## 3 系统路径

人才供应云 > 内部招聘 > 面试

## 4 主要操作

| **操作名称** | **操作简介** |
| --- | --- |
| 查询 | 展示所有候选人的面试编号、姓名、面试时间、类别、进度等完整信息，支持搜索和筛选查询。查看单个候选人的具体面试信息，包括面试方式、地址、综合评价等内容。 |
| 修改面试 | 对面试时间、地点等关键信息进行调整，适配招聘流程变动等需求。 |
| 取消面试 | 针对无需继续进行的面试，执行取消操作，更新面试进度状态。 |
| 催促答复 | 提醒候选人确认是否参加面试，推动面试流程顺畅推进。 |
| 修改答复 | 根据候选人反馈，更新其 “已答复”“未答复” 等答复状态。 |
| 催促评价 | 提醒未提交评价的面试官及时完成评价填写，确保评价环节不遗漏。 |
| 面试评价 | 面试官针对候选人表现填写评价，选择 “通过”“不通过”“待定” 等评价结论并录入综合评价分数。 |
| 修改总评 | 结合面试官评价情况，调整面试总评结果，为招聘决策提供依据。 |
