# 招聘职位（内部招聘）

# 总体介绍

## 1 功能介绍
招聘职位管理整合了职位信息维护、状态管控、合规审批、广告发布及候选人数据跟踪等全流程能力。通过标准化的信息录入与操作流程，实现招聘职位从创建、发布、运营到归档的全生命周期管理，解决了内部招聘信息分散、流程不规范、进度难追踪的问题，最终达成内部招聘效率提升与合规风险降低的效果，为企业快速补充内部人才提供稳定支撑。

## 2 应用场景
当企业存在内部岗位空缺需求时（如产品研发、运营支持、实习生储备等），可通过该功能创建招聘职位，明确职位要求与招聘计划。在招聘执行阶段，可根据候选人投递情况调整职位状态（如暂停招募）、补充发布广告至内部渠道，同时实时查看简历筛选、面试等各环节进度。

当职位招聘目标达成（如人员录用到位）或计划取消时，可完成职位关闭或归档，实现招聘业务闭环管理。此外，对于需合规审核的特殊职位，可通过内置审批流程确保招聘活动符合企业制度要求。

## 4 主要操作
| **操作名称** | **操作简介** |
| --- | --- |
| 查询 | 支持按职位编号、名称、状态（如招聘中、草稿、已完成）等多条件组合筛选，快速定位目标职位，并查看应聘人数、最新单据状态等核心数据。 |
| 新增 | 适用于企业产生新的内部招聘需求时，创建包含基本信息（如职位名称、招聘人数）、任职要求（如学历、工作年限）的完整职位档案，为后续候选人招募奠定基础。 |
| 修改 | 用于已创建职位的信息调整，适配招聘需求变更场景，如更新职责要求、调整计划完成日期等（关键信息如招聘类型、招聘管理组织不可修改）。 |
| 删除 | 已创建的职位草稿，在未发生审批、投递等业务时，可进行清理删除，废弃无用的数据。 |
| 启用/暂停 | 当招聘过程中出现需求暂缓（如岗位编制调整）时，执行该操作暂停职位招募，暂停期间仍可接收新的应聘申请，待需求恢复后可重新启用。 |
| 完成 | 当职位招聘目标达成（如计划招聘人数全部录用）时，将职位状态更新为 “已完成”，便于后续统计分析与档案查阅。 |
| 关闭 | 适用于招聘计划取消（如业务方向调整）的场景，彻底终止职位的招聘活动，避免无效候选人投递。 |
| 发布广告 | 在职位创建并通过审批后，将职位信息发布至指定内部招聘渠道（如内招官网），吸引内部员工或目标候选人应聘，可多次发布以扩大曝光。 |

# 暂停招聘职位

![上传图片](./images/01004b313599e6154021bcb62bb49235a31c.png)

## 1 操作应用场景
暂停招聘职位功能适用于招聘计划调整、业务/组织架构变动、职位信息需优化整改等场景，可有效降低合规风险，保障招聘流程规范有序。

职位暂停期间仍可正常接收候选人简历投递，待业务恢复后即可重启招聘流程。

# 完成/关闭招聘职位

![上传图片](./images/01008b75b14d8e804a1a949c6777a5a97aa6.png)

## 1 操作应用场景
当职位已招聘到规定人数且完成调动等相关人事手续后，可将该招聘职位标记为“已完成”；若因编制取消、招聘计划终止等原因，可关闭招聘职位。

已关闭/已完成的职位将不再接收新简历，避免无效投递，规范招聘流程。此操作一经执行，不可撤销。
