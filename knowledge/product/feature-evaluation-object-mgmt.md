# 1 功能介绍

评估对象指的是企业在开展绩效管理活动时，所明确界定的那些作为评估与管理目标的人员范畴。

# 2 应用场景

人力资源专员在考核活动内针对需参与的人员进行分类，管理及流程路由。

# 3 系统路径

目标绩效云>个人绩效考核>考核活动>考核活动详情>评估对象管理

# 4 主要功能介绍

## 4.1 术语介绍

**术语名称**

**术语解释**

考核组

针对人员进行分类的分类名称

考核责任人

特定角色，用于非系统标准角色外的自定义考核参与人，通常用于未在管理岗又担任考核责任的经理，小组长等

## 4.2 评估对象管理主要操作

### 4.2.1 操作说明

**操作**

**说明**

添加

方式一：从绩效档案

适用场景：从权限范围的绩效档案中直接添加人员，适用未参加过绩效活动的人员

权限说明：权限读取操作人针对绩效档案的管理权限，以【绩效管理组织】和【所属行政组织】定义操作人权限范围。

方式二：计划参与本周期

适用场景：从历史考核计划内标记的本周期人员中获取，适用于周期内稳定参与绩效活动的人员

删除

从考核活动内删除评估对象

前提条件：评估对象若已进行绩效活动，仅支持使用退出考核的方式，不支持直接删除

设置考核责任人

为评估对象设置考核责任人角色的具体人员。

适用场景：流程内启用了考核责任人角色，否则可不使用此功能

修改考核组

调整评估人员考核组

适用场景：针对人员进行分类管理

考核进度回退

将所选人员的流程进行回退操作

适用场景：跨流程环节进行回退操作

前提条件：评估对象未发起绩效结果确认流程，或未在校准活动执行中，则可回退

退出考核

将进行中的评估对象退出考核

适用场景：人员离职，或孕产假等场景导致无需参与绩效活动

重新加入考核活动

将退出活动的人员重新加入考核活动，被加入的人员将初始化状态，重新开始完整的绩效流程
