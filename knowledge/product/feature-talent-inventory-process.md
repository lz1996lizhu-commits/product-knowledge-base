## 盘点活动：盘点过程

**1 功能介绍**

在盘点活动推进过程中，基于盘点组权限范围查看并维护盘点对象，通过邀请填写问卷、维护盘点结果等操作，完成校准前的数据准备工作。

**2 应用场景**

企业盘点活动开始后，需要先明确本次盘点活动的盘点对象，并开展对盘点对象的问卷填写、评估；评估结果将作为最终盘点宫格落位的原始输入，支持后续校准活动。

**3 系统路径**

人才发展云>人才盘点>盘点活动>我管理的>盘点活动列表/详情页>盘点过程

**4 主要操作**

**4.1 启动盘点评估**

**4.1.1 操作应用场景**

用于启动盘点评估，发送消息给评价人，进行线上盘点评估。支持修改评价人，对评价人进行催办。

![上传图片](../images/product/0100919c938273274a519e932652f9030296.png)

**4.1.2 关键字段说明**

| **字段名称** | **详细解释** |
| --- | --- |
| 评价人 | 启动盘点评估，发送消息给评价人，进行线上盘点评估。 |
| 盘点评估状态 | 记录评价人进行线上盘点评估的状态。 |

**4.2 录入盘点评估**

**4.2.1 操作应用场景**

用于HR代录入盘点评估结果。

![上传图片](../images/product/01002edf1d8cf1b7471089873c8bd2dff728.png)

**4.2.2 操作说明**

计算百分比落位：当盘点活动的宫格配置中，横轴或纵轴取值类型为百分比，将在盘点过程列表中显示计算百分比落位按钮；勾选盘点对象并计算百分比落位后，将按照维度得分从高到低将盘点对象排序，并按照宫格中配置的划线标准，进行横纵轴落位。

**4.3 导入评估结果**

**4.3.1 操作应用场景**

用于导入综合结果和评估明细。

![上传图片](../images/product/010011f956c69a9c43718ac12d6cc604e468.png)

**4.3.2 关键字段说明**

| **字段名称** | **详细解释** |
| --- | --- |
| 维度结果 | 按盘点活动中配置的维度，展示对应的列，及导入的评估结果。 |
| 评估项结果 | 按盘点维度评估方案中配置的维度对应评估项，展示对应的列，及导入的评估结果。 |
| 异常信息 | 当员工发生调动、离职，或盘点活动中盘点人员范围配置发生变化时，展示提醒信息。 |

**4.4 修改盘点组**

**4.4.1 操作应用场景**

当盘点对象需要移交给其他协作人进行跟进时，可将其转移到对应的盘点组中。

![](../images/product/0109f18551873c19486d918b933f6b60157a.png)

**4.5 查看盘点结果**

**4.5.1 操作应用场景**

盘点完成后，HR查看最终盘点结果。

![上传图片](../images/product/0100fce50edecaf14d75ba717ca0b8022b61.png)

**4.5.2 关键字段说明**

| **字段名称** | **详细解释** |
| --- | --- |
| 校准前结果 | 导入综合评价后，即按照初始宫格落位，显示校准前结果。 |
| 校准后结果 | 显示校准后的宫格落位，若有多次校准会，取最新一次已完成的校准会结果。 |
| 最终盘点结果 | 盘点活动状态为"已完成"时，将显示"最终盘点结果"，优先取校准结果，若校准结果没值则取校准前结果。 |

**4.6 查看宫格分布**

**4.6.1 操作应用说明**

导入综合结果后，可整体查看盘点对象的初始落位。校准结束后，可整体查看盘点对象的最终落位。

![上传图片](../images/product/010003f9c216152d46ad99d51dc2138cb314.png)

**4.6.2 关键字段说明**

| **字段名称** | **详细解释** |
| --- | --- |
| 宫格地图 | 可以切换当前活动下配置的宫格地图。 |
| 宫格落位 | 优先取校准后结果，针对未校准的盘点对象，取校准前结果。 |
