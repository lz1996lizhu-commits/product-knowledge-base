# 考核活动介绍

考核活动用于管理具体组织内的绩效活动，明确具体的人员范围、表单及流程，并依据流程进行绩效各环节的管理。

## 1 功能介绍

考核活动用于管理具体组织内的绩效活动，明确具体的人员范围、表单及流程，并依据流程进行绩效各环节的管理。

## 2 应用场景

人力资源专员借助考核活动进行人员的绩效流程管理工作，覆盖指标制定、绩效评估、绩效校准、绩效汇总以及结果确认流程环节。

## 3 系统路径

目标绩效云 > 个人绩效考核 > 考核活动

## 4 主要功能介绍

### 4.1 术语介绍

| 术语名称 | 术语解释 |
| --- | --- |
| 考核周期 | 特定年份+特定周期组合。如2026Q1，代表2026年一季度 |
| 考核计划-明细执行计划 | 考核计划内某一特定周期的执行计划，执行计划关联表单及流程将被考核活动使用 |

### 4.2 考核活动新增

#### 4.2.1 操作流程

选择年份（示例：2026） > 选择考核计划（示例：集团年度考核计划） > 选择明细执行计划（集团一季度考核计划） > 确定表单流程及动态权限的引用方式

#### 4.2.2 配置说明

| 配置项 | 说明 |
| --- | --- |
| 表单流程及动态权限引用 | 方式一：引用考核执行计划。适用场景：明确使用考核执行计划配置的流程及表单。方式二：引用计划内其他周期活动。适用场景：如绩效执行过程在某考核活动内调整了流程及权限，可从已调整好的考核活动引用流程及动态权限 |
| 考核执行计划/明细执行计划 | 考核计划内某一特定周期的执行计划，执行计划关联的表单及流程将被考核活动使用，考核活动默认沿用考核计划的【绩效管理组织】及【所属行政组织】，并通过这两个字段控制考核活动的管理权 |

### 4.3 考核活动操作说明

#### 4.3.1 操作清单

| 操作项 | 说明 |
| --- | --- |
| 新增 | 新增考核活动的3种方式：按计划创建、按计划批量创建、直接创建。适用场景：①按计划创建：依据考核计划-考核周期执行计划创建当前年份对应的考核周期活动；②按计划批量创建：当同时管理多个评估对象范围的考核执行计划时，可一次创建多个考核活动；③直接创建：与考核计划无关，直接创建考核活动 |
| 启动 | 将考核活动状态设为执行中。适用场景：标记考核活动正式启动，并可以添加人员 |
| 撤销启动 | 将考核活动状态设为待执行。适用场景：撤销正在进行的考核活动，预期进行重置或删除。前提条件：考核活动内人员必须都退出考核或删除 |
| 结束 | 将考核状态设为已完成。适用场景：考核活动不再进行其他业务活动，标记完成。前提条件：所有考核人员都完成流程 |
| 撤销结束 | 将考核状态设为已完成。适用场景：重新将已完成的考核活动启用并进行业务活动 |
| 同步汇总规则 | 从考核计划上将配置的汇总规则同步至考核活动内使用 |

### 4.4 执行过程流程修改

#### 4.4.1 适用场景

适用于考核活动执行过程中，需启用或关闭某流程环节。

#### 4.4.2 操作流程

考核活动详情左侧面板 > 点击考核活动流程设置编辑图标

#### 4.4.3 前提条件

若子流程已被任一考核对象使用并启动，则该流程不可更改

### 4.5 执行过程权限修改

#### 4.5.1 适用场景

适用于考核活动执行过程中，调整流程节点的表单权限。

#### 4.5.2 操作流程

考核活动详情左侧面板 > 点击权限方案编辑图标
