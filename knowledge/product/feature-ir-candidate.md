# 候选人（内部招聘）

# 总体介绍

## 1 功能介绍
候选人管理支持招聘负责人在权限范围内对候选人的应聘信息进行一站式查询、操作与跟踪，涵盖招聘全流程推进（如筛选、面试、录用）及状态管理，实现招聘过程的高效管控。

## 2 应用场景
企业开展招聘工作时，招聘负责人需对接候选人从投递到录用的全流程管理，包括查询候选人基础信息、应聘进度，调整候选人所属职位或招聘环节，执行淘汰、锁定、通知发送等操作，以及录入笔试结果、安排面试、提交录用申请等流程推进动作，同时跟踪应聘过程中的评价、变动等信息，均需通过该功能实现。

## 3 系统路径
人才供应云 > 内部招聘 > 候选人

## 4 主要操作
| **操作名称** | **操作简介** |
| --- | --- |
| 查询 | 查询候选人编号、姓名、应聘职位、渠道、应聘日期、状态等基础信息，聚合查看候选人简历、面试评价、录用等全流程数据。 |
| 转职位 | 将候选人转移至合适的目标招聘职位，适配岗位需求调整。 |
| 转移环节状态 | 手动调整候选人所处招聘环节及对应状态，推进或调整招聘进度。 |
| 淘汰/恢复 | 对不符合要求的候选人执行淘汰操作，也可恢复已淘汰候选人的应聘资格。 |
| 锁定/解锁 | 锁定候选人应聘流程，避免他人误操作，解锁后可恢复他人的正常操作权限。 |
| 推荐筛选 | 将候选人推荐给用人经理等进行筛选，符合岗位要求的候选人可继续推进进入后续环节。 |
| 发通知 | 向候选人发送笔试等相关招聘通知，同步关键信息。 |
| 录入笔试结果 | 记录候选人笔试成绩及相关评价，作为筛选及推进招聘环节的依据。 |
| 安排面试 | 设置面试时间、类别、方式、地址等信息，发起面试安排并跟踪候选人和面试官的参与意愿。 |
| 录用申请 | 对符合招聘要求的候选人提交录用申请，生成录用申请单，推进录用审核流程。 |
| 确认变动 | 跟进候选人人事变动大类、变动状态，确认变动结果。 |

# 锁定候选人

![上传图片](./images/010054e4899fbf13419894a5f6de61eb1ad3.png)

## 1 操作应用场景
当企业在招聘流程中初步筛选出匹配的优质候选人，通过锁定操作，避免该候选人被其他招聘专员争抢或误删，确保专人跟进、信息不冲突，提升招聘效率与人才留存率。

## 2 关键字段说明
| **字段名称** | **详细解释** |
| --- | --- |
| 蓝锁 | 候选人已被锁定在当前招聘流程中，显示蓝锁时，当前用户可以对候选人进行操作。 |
| 灰锁 | 候选人已被锁定在其他招聘流程中，或者已被锁定在当前流程中但锁定者非当前用户；显示灰锁时，当前用户将被限制对候选人进行操作。 |

# 确认变动

![上传图片](./images/0100a1be7601a50a49acbba863ee74db0e88.png)

## 1 操作应用场景
当候选人录用审批已通过，人事专员可以为候选人发起调动等人事变动操作，员工调动完成后，招聘专员可以通过“确认变动”操作，标记候选人的人事变动状态。

## 2 操作校验说明
该操作将校验候选人“应聘状态”，当“应聘状态=待变动”时，允许操作。
