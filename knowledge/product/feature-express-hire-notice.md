# 录用通知（直通车）

# 总体介绍

## **1 功能介绍**

录用通知功能支持企业针对通过招聘流程的候选人创建、管理录用相关文件，可实现录用通知单的新增、修改、删除等操作，同时提供审批/免审批机制，能通过邮件、短信渠道发送通知，还支持候选人回复或由招聘专员代回复，高效完成录用沟通与入职衔接。

## **2 应用场景**

当企业完成候选人招聘筛选、确定录用后，可使用该功能生成标准化录用通知单，明确通知内容等关键信息；需调整通知信息时可进行修改操作；根据企业流程选择审批或免审批模式确认录用方案；通过邮件、短信向候选人推送录用通知及附件，同时接收候选人的录用回复或由招聘专员代为回复，保障录用流程顺畅推进。

## **3 系统路径**

人才供应云 > 招聘服务直通车 > 候选人 > 通知与回复

## **4 主要操作**

| **操作名称** | **操作简介** |
| --- | --- |
| 新增录用通知 | 为通过招聘流程的候选人创建录用通知单，明确通知方式及录用通知书内容。 |
| 修改录用通知 | 支持调整录用通知内容、通知方式及录用通知书详细内容等。 |
| 删除录用通知 | 当录用通知单处于“暂存”状态时，支持进行删除操作，清理无效数据。 |
| 录用通知审批 | 按照企业设定流程，提交录用通知供相关负责人审核确认，审核通过后可发送。 |
| 录用通知免审批 | 符合企业免审批规则的录用场景，无需审核直接确认录用通知内容。 |
| 发送邮件通知 | 将录用通知书（可包含加密/免密附件）通过电子邮件发送给候选人，同步抄送给相关人员。 |
| 发送短信通知 | 向候选人手机发送录用告知短信，提示查收详细录用信息。 |
| 候选人回复 | 候选人接收通知后，通过经手机/邮箱验证的登录链接，可选择“接受录用”或“拒绝录用”完成回复。 |
| 招聘专员代回复 | 招聘专员在候选人未自主回复时，代为提交“接受录用”或“拒绝录用”的回复结果。 |
| 失效录用通知 | 为保证业务实效性和合规安全，招聘专员可设置录用通知书失效时间，或手动操作失效录用通知。 |

# 新增录用通知

## **1 操作应用场景**

候选人已完成录用申请，或无需进行录用审批时，招聘专员可以为候选人新增录用通知单，在单据中录入邮件、短信通知，录用通知书等内容后提交申请或直接发送。

## **2 操作校验说明**

新增录用通知单时，会对候选人应聘状态、最新录用申请状态、最新入职协同状态、历史录用通知状态进行交叉校验。

| **校验条件** | **操作结果** |
| --- | --- |
| 应聘状态=已结束 | 不允许 |
| 应聘状态=未开始/流程中 | 允许 |
| 入职协同状态=暂存/已提交/待重新提交/审批中 | 不允许 |
| 入职协同状态=发起入职中/发起入职成功 | 不允许 |
| 入职协同状态=已入职/已转正/已离职 | 不允许 |
| 入职协同状态=审批通过/审批不通过/免审批/已废弃/已取消入职/发起入职失败/（空） | 允许 |
| 录用申请状态=暂存/已提交/待重新提交/审批中 | 不允许 |
| 录用申请状态=审批不通过 | 允许 |
| 录用申请状态=审批通过/免审批/已废弃/（空） | 允许 |
| 录用通知状态=暂存/已提交/待重新提交/审批中 | 不允许 |
| 录用通知状态=已发送/已接受/已拒绝 | 允许 |
| 录用通知状态=审批通过/免审批 | 允许 |

# 发送录用通知

## **1 操作应用场景**

候选人录用通知单审批完成或免审批时，招聘专员可以为候选人发送录用通知。因特殊情况，候选人未收到录用通知时，招聘专员可以重复发送相同的通知。

## **2 操作校验说明**

发送录用通知时，会对候选人最新录用通知状态进行校验，当状态为“已发送/审批通过/免审批”时，允许发送。

# 回复录用通知

## **1 操作应用场景**

为候选人发送录用通知后，候选人可以通过在线链接回复是否接受录用，在候选人不便回复时，招聘专员可在系统中代为回复。

## **2 操作校验说明**

候选人或招聘专员回复录用通知时，会对录用通知状态进行校验，仅状态为“已发送”时允许回复。

# 失效录用通知

## **1 操作应用场景**

录用通知书失效时间超过设定值，但仍未进行回复，或由于企业、候选人改变录用意向时，可将录用通知设置为“失效”状态。此外为候选人创建新的录用通知时，原有录用通知也会自动失效。

## **2 操作校验说明**

手动操作失效录用通知时，会对候选人最新录用通知单状态进行校验，当状态为“已发送/已接受/已拒绝”时，允许操作。已失效的录用通知不可恢复，如有需要可重新创建。
