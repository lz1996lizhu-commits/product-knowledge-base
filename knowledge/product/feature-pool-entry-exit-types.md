# 入池类型和出池类型

## 功能介绍

入池类型用于发起入池申请单时标识人才进入储备池的来源方式；出池类型用于发起出池申请单时标识人才退出储备池的原因分类。

## 应用场景

企业需要准确记录每位储备人才的入池类型和出池类型，HR管理员提前配置好分类选项，确保业务人员在发起入池单或出池单时有统一、规范的类型可选。

## 系统路径

- 人才发展云 > 人才储备池 > 入池类型列表
- 人才发展云 > 人才储备池 > 出池类型列表

#### 关键字段说明

| 字段名称 | 详细解释 |
| --- | --- |
| 编码 | 入池/出池类型的唯一标识编码 |
| 名称 | 入池/出池类型的名称，如"业务部门推荐""达标出池" |
| 使用状态 | 控制该类型是否在申请单中可被选择，可选"可用"或"禁用" |

#### 操作校验说明

- 已被申请单引用的类型不可删除。
