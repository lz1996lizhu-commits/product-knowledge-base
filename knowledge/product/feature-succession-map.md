# 继任地图

## 功能介绍

继任地图以组织架构为维度，图形化展示各组织下的关键岗位及继任者分布情况。通过继任地图，管理者可以直观了解不同层级组织的继任人数、关键岗位数量、继任梯队构成，并支持对关键岗位人才进行对比分析，辅助继任决策。

## 应用场景

当企业需要从组织视角全盘掌握继任人才布局时，可使用继任地图进行可视化查看和分析。典型场景包括：

1. 按集团、事业部、部门等组织架构层级查看继任覆盖情况；
2. 定位关键岗位，查看当前任职者及第一、第二、第三梯队继任者；
3. 对多名继任候选人进行人才对比。

## 系统路径

人才发展 > 继任管理 > 继任地图

## 主要操作

### 按组织架构查看继任地图

![继任地图](../images/product/01000a393f7190f04b899365902609bd2171.png)

#### 操作应用场景

当管理者需要了解某一组织及其下属组织的继任人才整体布局时，可通过组织架构视图逐级展开，快速查看各组织的继任人数、关键岗位数量及下设组织情况。

#### 页面构成说明

| 页面区域 | 说明 |
| --- | --- |
| 组织卡片 | 每个组织以卡片形式展示，包含组织名称、继任人数、关键岗位数量、下设组织数量。 |
| 层级展开 | 点击"下设组织"可向下展开子组织，支持按层级逐级查看。 |
| 顶部工具栏 | 支持切换视图、展开层级、导出PNG、缩放等操作。 |
| 关键岗位链接 | 组织卡片上的"关键岗位"数量可点击，点击后展示该组织下的关键岗位继任梯队。 |

### 查看关键岗位继任梯队并进行人才对比

![关键岗位继任梯队](../images/product/01007672da268028450fb51dadc6647c5449.png)

![人才对比](../images/product/01006982fc0039bc4270b3e9856b2058ad1d.png)

#### 操作应用场景

当需要评估某一关键岗位的继任者准备情况，或需要在多名候选人之间进行比较时，可先查看该岗位的继任梯队，再选中候选人进行人才对比，辅助继任决策。

#### 页面构成说明

| 页面区域 | 说明 |
| --- | --- |
| 关键岗位卡片 | 展示岗位名称、当前任职者头像及姓名，以及各梯队继任者。 |
| 当前任职者 | 显示担任该岗位的人员，通常展示头像、姓名及工号。 |
| 继任梯队 | 按第一梯队、第二梯队、第三梯队展示继任者，支持查看每个梯队的人员构成。 |
| 人才对比面板 | 选中候选人后，系统展示人才盘点、经验背景等对比维度。 |
