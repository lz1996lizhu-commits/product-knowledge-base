# 任职资格整体介绍

## 1 产品概述

### 1.1 产品介绍

为实现全方位人才管理，企业需根据岗位要求和人才需求构建任职资格管理标准，并基于标准建立认证流程，对任职者必须具备的知识、经验和技能等方面进行客观评估，从而高效完成任职资格管理。

### 1.2 角色心声

| 角色 | 关注点 |
| --- | --- |
| 待认证员工 | 怎么判断我是否满足任职资格要求？认证流程是什么样的？参加认证后需要多久才能获得我的认证结果？ |
| 人才发展 HR | 既要处理这么多员工的申请，又要完成后续的安排与跟进，信息这么多，我怎么跟得过来？ |
| 直线经理人 | 每次任职资格评定都要一一了解员工的过往申报记录，还得面对面指导员工申报，效率太低。 |
| 评委 | 目前评定的过程令我感到困惑，我想了解是否有相关的评分指引和标准可供参考？ |

### 1.3 业务场景

基于任职资格业务的多种场景，企业需根据对人才的专业技能要求构建分类分级的任职资格管理标准，并通过认证流程完成对员工职业化技能的全面评价，找出员工与组织岗位之间的实际差距，明确员工培训提升和工作改进的方向。

## 3 亮点特性

### 3.1 多样化的任职资格标准

依托于企业的岗位要求与人才需求，专员可结合企业的能力素质模型，完成分层分类的任职资格标准构建，以提供给企业内的不同组织、不同群体使用。

### 3.2 周期性的认证计划

基于对员工的能力评估需求，企业可建立并启动周期性的任职资格认证计划，同时支持跟进、复盘计划执行情况，完成任职资格认证的持续调优。

### 3.3 差异化的认证流程

支持企业根据不同任职资格标准对认证流程进行灵活自定义，提供包含认证申请、员工自评、资格审查、认证考核、认证公示等认证活动环节。

### 3.4 可靠的申诉途径

提供认证申诉渠道，员工可对认证结果提起申诉，从而获得重新评估和验证的机会，以确保认证结果的准确性和公正性。
