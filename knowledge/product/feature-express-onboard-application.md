# 入职协同申请（直通车）

# 总体介绍

## 1 功能介绍
入职协同申请是招聘与入职业务衔接的核心功能，用于记录候选人拟入职的关键信息、上传入职相关附件，支持新增、修改、删除、审批、免审批等操作，实现入职流程的规范化、高效化管理，并为后续办理员工入职手续提供数据支持。

## 2 应用场景
当企业完成招聘流程并确定录用候选人后，需通过该功能发起入职协同申请，录入拟入职公司、部门、岗位等信息，并上传体检报告、学历验证报告等附件；若申请信息有误，可进行修改；若申请发起后无需继续推进，可将其删除；部分场景需按企业流程完成审批，符合特定条件的申请可走免审批通道，最终完成入职手续的前置协同。

## 3 系统路径
人才供应云 > 招聘服务直通车 > 候选人 > 入职协同

## 4 主要操作
| **操作名称** | **操作简介** |
| --- | --- |
| 新增入职协同申请 | 用于候选人录用后，首次录入拟入职信息及上传相关附件，发起入职协同流程。 |
| 修改入职协同申请 | 用于修正拟入职信息、补充或替换附件内容。 |
| 删除入职协同申请 | 当入职协同单处于“暂存”状态时，支持删除数据，终止该申请流程。 |
| 入职协同申请审批 | 用于相关负责人对入职协同申请进行审核，确认信息无误后批准流程推进。 |
| 入职协同免审批 | 用于符合企业免审批规则的场景，无需审批即可直接通过入职协同申请。 |
| 发起入职 | 当入职协同审批通过或处于免审批场景时，可在招聘模块直接发起入职，解决人工传递入职信息效率低、易出错的问题，通过系统推送完成入职业务发起与数据传递。 |
| 取消入职 | 当发起入职信息有误，或经招聘专员确认无需继续推进入职业务时，可在招聘模块取消入职，并将信息同步至入职模块。 |
| 人事变动状态回传 | 应用于新员工完成入职/转正/离职手续后，解决招聘模块无法实时获取员工入职结果的问题，并自动同步状态至招聘端。 |
