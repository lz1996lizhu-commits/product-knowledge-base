# 人才发展云版本更新说明（V8.0.15）

发布说明

发布版本：CONSTELLATION.HRPROV8.0.15_0627

上线日期：2026-06-27

发布内容

*加粗的内容包含了升级注意事项的说明，请您使用时重点关注。

# 人才档案

- 【功能优化】优化了人才档案管理关系维护弹窗，支持批量维护管理关系
- 【功能优化】优化了人才画像整体页面效果，支持查看人才全景信息，包括人事、绩效等数据

# 任职资格

- 【功能优化】优化了任职资格/职级评定的申报和评议等环节交互，支持用户使用AI辅助进行长文本总结，新增AI辅助功能的菜单权限设置
- 【问题修复】修复了【任职资格】受控基础资料预制数据升级定时任务处理问题，确保预制数据能够准确按时完成升级

# 人才盘点

- 【功能优化】优化了盘点过程，支持基于盘点评估方案生成盘点评估问卷，支持盘点过程快速批量录入盘点评估项和结果
- 【功能优化】优化了人才管理的场景联动，支持盘点结果快捷推荐至储备池/继任梯队，支持储备池快捷推荐至继任梯队，支持干部酝酿候选人从储备池/继任梯队快速添加
- 【问题修复】修复了人才发展云中多个应用预置脚本因对相同表主键并发执行导致的数据冲突与执行异常问题，通过全量扫描与整改保障了多应用间脚本执行的稳定性

# 继任计划

- 【新功能】新增了继任计划功能，支持定义关键岗位及岗位要求，支持基于岗位要求搭建继任梯队，支持基于组织架构图查看继任梯队及继任人才卡

# 干部管理

- 【功能优化】优化了干部酝酿详情页的候选人卡片交互，支持通过酝酿岗位或职位智能推荐继任候选人及储备池人才
