# 继任者管理

## 功能介绍

继任者管理用于以员工为维度集中管理所有继任者信息。HR 可以查看每位继任者对应的关键岗位、就绪程度、继任状态，并维护其培训事件记录与附件，实现对继任人才发展的全过程跟踪。

## 应用场景

当企业需要从员工视角掌握核心人才的继任安排和培养进展时，可使用继任者管理功能。典型场景包括：

1. 查看某名员工担任哪些关键岗位的继任者及所在梯队；
2. 记录和管理继任者参加的培训事件及相关附件。

## 主要操作

### 以员工视角查看继任情况

![继任者管理列表](../images/product/0100ab01909ca91648118402497b7e26a5e6.png)

![继任者详情页](../images/product/01004e01fe51b266499eb5ba45cb0661c1fb.png)

#### 操作应用场景

当 HR 需要了解某位员工是否已被列为继任者、担任哪些关键岗位的继任角色，以及当前就绪程度时，可通过继任者管理列表和详情页进行查看。

#### 关键字段说明

| 字段名称 | 详细解释 |
| --- | --- |
| 关键岗位 | 该员工担任继任者的目标关键岗位。 |
| 继任状态 | 继任关系的生效状态，如生效中、已失效。 |
| 继任生效时间 | 该继任关系开始生效的日期。 |

### 维护继任者培训记录

#### 操作应用场景

为提升继任者的岗位胜任力，HR 或业务负责人需要记录继任者参与的培训事件，如领导力培训、专业能力培训等，以便跟踪培养进展和评估准备度。

#### 关键字段说明

| 字段名称 | 详细解释 |
| --- | --- |
| 培训日期 | 培训事件发生的日期。 |
| 培训名称 | 培训事件的名称，如"高层管理能力培训"。 |
| 附件 | 支持上传文件或粘贴截图，作为培训记录的补充材料。 |
