## 盘点活动模板

**1 功能介绍**

盘点活动模板是人才盘点模块中的模板管理功能，用于预先定义盘点活动的标准化配置方案。通过模板，企业可以将盘点维度、人员范围、盘点工具、宫格配置等关键要素固化为可复用的模板，在后续创建盘点活动时直接引用，大幅提升盘点活动的创建效率和配置一致性。

**2 应用场景**

企业针对同类型盘点，通常会使用一套固定的盘点维度、盘点工具、宫格，希望能预置一套模板，以便每次同类型盘点都可以直接引用模板，快速创建盘点活动。

**3 系统路径**

人才发展云>人才盘点>基础配置>业务模板>盘点活动模板

**4.1.1 页面构成说明**

| **页面内容** | **说明** |
| --- | --- |
| 基本信息 | 展示和维护模板的核心属性。 |
| 盘点人员范围配置 | 定义模板默认的人员筛选范围，支持设置多组条件组合，并可控制在实际盘点活动中是否允许调整。 |
| 盘点内容配置 | 配置模板中的盘点评估维度（如能力、潜力、绩效）及其关联的评估方案，支持多维度配置。配置本次盘点活动中，是否需要盘点优劣势、发展方向，是否同步进行推荐至储备池和推荐至继任梯队。配置评价人进行在线评估时，问卷显示的内容。 |
| 宫格配置 | 配置模板使用的宫格，包括横纵轴、刻度区间、主题色等，并可控制在实际盘点活动中是否允许调整。 |
| 盘点活动清单 | 展示基于当前模板创建的所有盘点活动，包含活动的基本信息、状态、人数等详细数据，便于追踪模板的使用情况。 |

**4.1.2 字段说明**

| **字段名称** | **详细解释** |
| --- | --- |
| 是否允许在盘点活动中调整 | 若选择"允许调整"，则盘点活动引用模板后，仍可在活动中调整；若选择"仅可调整未锁定条件"，则盘点活动引用模板后，可以在活动中调整未锁定的字段；若选择"不允许调整"，盘点活动引用模板后，不可以在活动中调整。 |
| 切换开闭区间 | 当按照分数或百分比来设置划线标准时，默认左闭右开区间，可通过"切换开闭区间"按钮，切换为左开右闭。 |
