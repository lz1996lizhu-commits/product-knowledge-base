# 候选人（直通车）

# 总体介绍

## 1 功能介绍
候选人管理支持从生态系统导入、手动获取候选人信息，提供新增/批量新增、简历解析、修改、删除、结束/恢复应聘、修改管理人等全流程操作，实现候选人信息的集中管理与招聘流程的高效推进。

## 2 应用场景
企业开展社会招聘等招聘业务时，可通过该功能整合多渠道候选人资源（生态系统导入、手动录入等）；招聘过程中需完善、调整候选人信息（如基本信息、应聘职位等）时，可通过修改、简历解析功能实现；针对候选人招聘状态变化（如终止招聘、重新纳入招聘流程），可通过结束/恢复应聘功能处理；同时支持批量操作，提升多候选人管理效率，满足企业不同招聘场景下的候选人管理需求。

## 3 系统路径
人才供应云 > 招聘服务直通车 > 候选人

## 4 主要操作
| **操作名称** | **操作简介** |
| --- | --- |
| 新增候选人 | 手动录入单个候选人的应聘信息、基本信息，支持上传简历并完成解析，适用于零散候选人添加场景。 |
| 批量新增候选人 | 一次性上传多个候选人简历，系统自动解析并填充信息，高效完成多候选人批量录入。 |
| 修改候选人 | 调整候选人的应聘信息、基本信息，满足信息完善或更正需求。 |
| 删除候选人 | 当候选人未在录用、入职协同等任何环节产生业务数据时，支持移除候选人信息，适用于无效候选人数据清理场景。 |
| 导入候选人 | 从生态系统中获取候选人资源，直接同步至候选人列表，减少重复录入工作。 |
| 简历解析 | 上传简历附件，系统自动解析简历内容并填充至对应字段，提升信息录入准确性与效率。 |
| 结束应聘 | 终止候选人的当前招聘流程，适用于不符合招聘要求或主动放弃应聘的情况。 |
| 恢复应聘 | 将已结束应聘的候选人重新纳入招聘流程，适用于需再次评估的场景。 |
| 修改管理人 | 变更候选人的负责招聘人员，确保招聘工作的顺畅交接与责任明确。 |

# 新增/批量新增候选人

## 1 操作应用场景
当未集成第三方招聘系统，或仅需要在直通车新增候选人进行录用及入职协同管理时，可选择手动新增单个或多个候选人。在新增候选人时，可通过AI简历解析功能，快速解析简历附件内容并填充到系统表单。

## 2 操作校验说明
在批量新增候选人时，“候选人姓名”为系统必要信息；如果用户未上传原始简历附件，将无法保存数据并新增候选人。如果用户已上传原始简历附件，但简历解析未成功，仍可正常保存数据，“候选人姓名”字段将以原始简历文件名进行填充，超长部分会被自动截取。

# 导入候选人

## 1 操作应用场景
当已集成第三方招聘系统，候选人在第三方招聘系统已完成招聘各项考核，需要进行录用或入职协同管理时，可以在第三方招聘系统操作“导入候选人”，以Moka为例，候选人的简历、考试测评、面试评价、附加信息、应聘职位等内容将同步至直通车。

# 删除候选人

## 1 操作应用场景
当新增/导入候选人数据存在错误，需要废弃时，用户可以操作删除候选人。

## 2 操作校验说明
新增/导入的候选人，在未发生任何录用申请、录用通知、入职协同业务时，候选人的应聘状态为“未开始”，此时允许用户操作删除候选人。
