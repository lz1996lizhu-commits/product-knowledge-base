# 人才发展云版本更新说明（V8.0.17）

发布说明

发布版本：CONSTELLATION.HRPROV8.0.17_0724

上线日期：2026-07-24

发布内容

*加粗的内容包含了升级注意事项的说明，请您使用时重点关注。

# 人才档案

- 【功能优化】优化了人才档案详情页支持手动打标的能力，通过新增手动打标弹窗实现对人才标签的灵活管理，提升人才画像的准确性和运营效率
- 【功能优化】优化了人才档案详情页的信息展示结构，新增标签卡片以支持更清晰的分类信息呈现，提升用户查阅效率
- 【功能优化】优化了人才发展云中人才档案的锚点逻辑，提升用户在档案长页面中快速定位目标信息的准确性和操作流畅度
- 【功能优化】优化了人才发展云公共事项的预置数据处理机制，通过调度任务自动判断是否为星空环境，若是则执行星空预置数据包并禁用星瀚预置方案数据，若否则不作处理

# 职级评定

- 【功能优化】优化了职级评定活动切换时的遗留内容处理流程，增加了评审安排的开关控制能力，提升流程配置的灵活性和操作安全性
- 【功能优化】优化了职级评定操作治理流程，提升了评定过程的数据一致性和操作规范性，强化了关键环节的权限控制
- 【功能优化】优化了人才发展云职级评定中批量职级职等的保存、提交、提交并生效操作，补充了关键环节的许可校验触点，提升权限控制的完整性与业务操作安全性
- 【功能优化】优化了AI功能以适配星空海外版，提升海外用户在人才发展云中任职资格与职级评定场景下的智能化体验
- 【功能优化】优化了晋升提名中晋升建议下拉选项的二开拓展能力，支持自定义下拉选项且无需校验建议职位和建议职等，直接放开编辑权限，提升二次开发灵活性

# 任职资格

- 【功能优化】优化了任职资格业务规则预置场景中入参多个结果字段的配置体验，增加了参数显示名以提升可读性和规则配置效率
- 【功能优化】优化了任职资格认证流程结果表的"生/失效"状态维护能力，提升状态更新的准确性与业务流程的连贯性
- 【功能优化】优化了认证公示详情中结果决议单与认证申请单的权限关联逻辑，确保用户在具备申请单查看权限时可同步访问对应的决议单信息，提升任职资格认证流程中数据权限的一致性与业务连贯性。**注意：若系统存在自定义权限集成或二开场景，需检查相关权限判断逻辑是否依赖原独立权限结构并进行适配**
- 【功能优化】优化了任职资格操作治理流程，提升了操作的规范性与数据的一致性
- 【功能优化】优化了任职资格认证/职级评定中评委为平台人时的头像获取方式，提升头像加载的稳定性和显示一致性
- 【功能优化】优化了人才发展云任职资格HR端认证申请的选人、保存、提交流程，补充关键操作环节的许可校验触点，提升系统权限管控的完整性

# 人才盘点

- 【功能优化】优化了干部管理和人才盘点的操作治理能力，提升了操作流程的规范性和数据的一致性
- 【功能优化】优化了人才发展云中人才盘点、人才储备池、继任计划及基础服务模块的流程导航能力，支持预置星空流程直接导航至星空的包，提升模块间跳转效率与用户体验
- 【功能优化】优化了人才发展云中人才档案、人才盘点、职级评定、干部管理及人才星图模块的预置星空流程导航能力，支持快速跳转至对应的星空包，提升用户在多模块间操作的连贯性与效率

# 人才星图

- 【功能优化】优化了人才发展云人才星图模块中人才搜索功能的回归测试覆盖能力，提升了搜索逻辑的稳定性和结果准确性
