# 继任候选人推荐

## 功能介绍

继任候选人推荐用于收集和管理由部门推荐或人才盘点推荐的关键岗位继任候选人信息。HR 可以在列表中查看候选人的推荐来源、推荐就绪程度、提名状态等信息，并对推荐记录进行提名、不受理等后续处理，从而规范继任候选人的准入流程。

## 应用场景

当业务部门或人才盘点时发现具备关键岗位胜任潜力的员工时，可通过继任候选人推荐功能进行登记和流转。典型场景包括：

1. 人才盘点、人才搜索推荐至继任梯队；
2. HR 对推荐候选人进行初步审核并发起正式提名；对不符合要求的推荐记录进行不受理处理。

## 系统路径

人才发展 > 继任管理 > 继任候选人推荐

## 主要操作

### 新增继任候选人推荐

![继任候选人推荐](../images/product/01006eb8eaf456504cfa9892d262f8888ed4.png)

#### 操作应用场景

HR线下收到继任者推荐，可在此录入推荐信息。

#### 关键字段说明

| 字段名称 | 详细解释 |
| --- | --- |
| 提名状态 | 推荐记录的当前处理状态，如待提名、已提名、不受理等。 |
| 推荐关键岗位 | 候选人被推荐担任的关键岗位。 |
| 推荐就绪程度 | 推荐人评估的候选人当前胜任程度，如第一梯队、第二梯队、第三梯队。 |
| 推荐来源 | 候选人推荐的来源渠道，如部门推荐、人才盘点。 |
| 推荐意见 | 推荐人填写的关于候选人的评价或推荐理由。 |
| 推荐人 | 发起该推荐记录的人员姓名和工号。 |

#### 操作校验说明

新增推荐记录时，系统会校验候选人是否已存在相同关键岗位、相同梯队的待处理推荐，避免重复推荐。
