# 人才供应云版本更新说明（V8.0.17）

发布说明

发布版本：CONSTELLATION.HRPROV8.0.17_0724

上线日期：2026-07-24

发布内容

*加粗的内容包含了升级注意事项的说明，请您使用时重点关注。

# 内部招聘

- 【功能优化】优化了面试安排通知与推荐筛选通知中的回复链接权限控制逻辑，确保仅具备相应权限的用户可访问操作链接，提升系统安全性与用户体验
- 【功能优化】优化了人才供应-内部招聘模块在26R3版本中的权限遗留问题处理，提升了系统权限控制的完整性和安全性
- 【功能优化】优化了内部招聘操作治理流程，提升了招聘操作的规范性与数据一致性
- 【功能优化】优化了内部招聘中保存应聘建议的功能逻辑，通过精简数据传输结构减少token消耗，提升系统处理效率
- 【功能优化】优化了AI功能在星空海外版中的适配性，提升内部招聘场景下海外用户的人才匹配与简历筛选体验
- 【功能优化】优化了内部招聘录用审批流程支持查看候选人简历，提升了审批人员查阅候选人信息的便捷性与审批效率
- 【功能优化】优化了人才供应云招聘直通车及内部应聘场景下预置星空流程的导航能力，提升跳转至星空包的响应效率与操作流畅性
- 【功能优化】优化了人才供应云公共事项的预置数据处理机制，通过调度任务自动判断是否为星空环境，若是则执行星空预置数据包并禁用星瀚预置方案数据，若否则不作处理

# 招聘服务直通车

- 【功能优化】优化了人才供应-招聘服务直通车在26R3版本中的权限遗留问题处理，提升了模块访问与操作的权限控制准确性
- 【功能优化】优化了人才供应-招聘服务直通车中状态回传Moka的逻辑，提升系统间状态同步的准确性与及时性
