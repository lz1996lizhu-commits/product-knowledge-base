# 人人面试官

# 总体介绍

## **1 功能介绍**

内部招聘面试官工作台是服务于面试官的招聘管理工具，整合待办任务管理、简历筛选、面试评价等核心功能，支持面试官高效处理内部招聘全流程相关工作，实现招聘任务可视化、筛选评价数字化。

## **2 应用场景**

当企业开展内部招聘工作时，面试官可通过该功能查看所有待办招聘任务（待筛选、待面试、待评价）及面试日程；接收简历筛选任务后，查阅候选人信息并反馈筛选结论；完成面试后，填写面试评价表并提交评价结果，全程跟进内部招聘候选人的筛选与面试环节。

## **3 系统路径**

人才供应云 > 人人面试官

## **4 主要操作**

| **操作名称** | **操作简介** |
| --- | --- |
| 查看待办任务 | 展示待筛选、待面试、待评价任务数量，支持快速定位待处理工作事项。 |
| 查看面试日历 | 按日/周视图展示面试日程，清晰呈现面试时间、地点等信息。 |
| 查看筛选任务 | 展示内部招聘候选人的编号、应聘职位、推荐时间、反馈状态等信息，支持搜索与过滤。 |
| 反馈筛选结论 | 查阅候选人基本信息、任职经历，选择“合适”“不合适”“转职位”“待定”结论并填写意见后提交。 |
| 查看面试任务 | 展示候选人面试标题、应聘职位、面试日期、地点、处理状态等信息，支持搜索筛选。 |
| 提交面试评价 | 查看候选人简历详情，填写综合评价内容，选择“通过”“不通过”“待定”结果，支持上传附件。 |
