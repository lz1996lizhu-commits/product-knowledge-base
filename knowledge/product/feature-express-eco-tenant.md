# 生态租户

# 总体介绍

## **1 功能介绍**

生态租户是金蝶AI HR中用于维护第三方招聘系统租户信息的功能，可建立生态组织与招聘管理组织的映射关系，并能基于已配置的租户、生态组织信息，精准判定从第三方招聘系统同步至金蝶AI HR的数据管理归属，实现第三方招聘数据同步的规范化、精细化管理。

## **2 应用场景**

企业在金蝶AI HR中对接各类第三方招聘系统时，需通过该功能维护第三方招聘系统的租户基础信息；当需要明确第三方招聘系统与金蝶AI HR内部组织的对应关系，以及确定第三方同步数据在金蝶AI HR中的管理归属主体时，可使用本功能完成组织映射与归属判定，保障第三方招聘数据同步后管理权责清晰。

## **3 系统路径**

人才供应云 > 招聘服务直通车 > 生态连接 > 生态租户

## **4 主要操作**

| **操作名称** | **操作简介** |
| --- | --- |
| 新增生态租户 | 用于在金蝶AI HR中首次添加第三方招聘系统的租户信息，为后续组织映射和数据归属判定奠定基础。 |
| 修改生态租户 | 当第三方招聘系统租户信息发生变更，或前期配置信息有误时，可修改已维护的生态租户信息。 |
| 删除生态租户 | 当第三方招聘系统租户合作终止，或租户信息配置错误且无需保留时，可删除对应的生态租户信息。 |
| 组织映射 | 针对已维护的生态租户，配置其生态组织与金蝶AI HR内部招聘管理组织的对应关系，作为数据归属判定的核心依据。 |
| 数据管理归属 | 基于已配置的生态租户信息、生态组织与招聘管理组织的映射关系，自动判定第三方招聘系统同步至金蝶AI HR数据的管理归属。 |

# 数据管理归属

## **1 操作应用场景**

从第三方招聘系统导入候选人、招聘职位数据，需要判定数据归属的招聘管理组织、行政组织，以进行数据权限控制。此外用户还可以使用单据预置的“管理人”字段，实现按人管控数据权限。

## **2 操作校验说明**

从第三方招聘系统导入候选人和招聘职位数据后，系统首先将根据入参的API Key等信息，明确数据归属的生态租户；根据生态租户中招聘管理组织、行政组织的对应关系，通过数据的生态组织判定数据所属的招聘管理组织；如果未维护生态组织，或相同生态租户存在多个招聘管理组织，则数据自动归属于默认的招聘管理组织。
