# 目标绩效云-集成场景用例-绩效档案

用例总数: 3

## 用例 173: 劳务派遣入场后离职、再入职、调动、兼职等业务操作生成员工变动任务，并使用员工的任职经历生成绩效档案

**功能路径**: 目标绩效云(pro)-集成场景用例-绩效档案

**功能说明**: 
1.核心人力云已配置公司内调动生成组织分配、跨公司调动生成组织分配；再入职不创建新员工但创建组织分配，不创建新员工不创建组织分配2.行政组织A、B、C、D、E、F对应的绩效管理组织BU1，X、Y绩效管理组织BU23.个人绩效考核在员工基础配置-非主任职参与考核=参与 4.用户具有核心人力云和个人绩效考核的所有权限

**步骤描述**: 
1.在入职管理劳务派遣③入职到行政组织A，入职成功后进入个人绩效考核-员工变动任务和绩效档案查看信息
2.在调配管理对员工③进行公司内调动到行政组织X，调动后进入个人绩效考核-员工变动任务和绩效档案查看信息
3.在调配管理对员工③进行公司内调动到行政组织B，调动后进入个人绩效考核-员工变动任务和绩效档案查看信息
4.在离职管理对员工③进行离职，离职后进入个人绩效考核-员工变动任务和绩效档案查看信息
5.在入职管理再入职（创建新员工但继承工号）雇佣员工③到行政组织A，入职成功后进入个人绩效考核-员工变动任务和绩效档案查看信息
6.在调配管理对员工③进行公司内调动到行政组织X，调动后进入个人绩效考核-员工变动任务和绩效档案查看信息
7.在调配管理对员工③进行公司内调动到行政组织B，调动后进入个人绩效考核-员工变动任务和绩效档案查看信息
8.在调配管理对员工③进行跨公司兼职到行政组织C，兼职后进入个人绩效考核-员工变动任务和绩效档案查看信息
9.在调配管理对员工③进行公司内调动到行政组织Y，调动后进入个人绩效考核-员工变动任务和绩效档案查看信息
10.在调配管理对员工③进行公司内兼职到行政组织Z，兼职后进入个人绩效考核-员工变动任务和绩效档案查看信息
11.删除以上变动任务生成的绩效档案
12.新增、批量新增、导入等操作员工③的任职经历信息，查看档案变化

**预期结果**: 
1.员工变动任务新增该员工入职信息，自动处理。绩效档案新增该员工档案③-0001,任职经历信息为行政组织A相关信息，档案状态=正常使用
2.员工变动任务新增该员工调动流出、流入信息，自动处理。绩效档案新增该员工档案③-0002，显示信息为行政组织X相关信息。
3.员工变动任务新增该员工调动流出、流入信息，自动处理。绩效档案变更该员工档案③-0001，升级版本为V0002，显示信息为行政组织B相关信息。
4.员工变动任务新增该员工离职信息，自动处理。所有绩效档案的档案状态=停止使用。
5.员工变动任务新增该员工入职信息，自动处理。绩效档案新增该员工档案③-0003,，任职经历信息为行政组织A相关信息，档案状态=正常使用。
6.员工变动任务新增该员工调动流出、流入信息，自动处理。绩效档案新增该员工档案③-0004，显示信息为行政组织X相关信息。
7.员工变动任务新增该员工调动流出、流入信息，自动处理。绩效档案变更该员工档案③-0003，升级版本为V0002，显示信息为行政组织B相关信息。
8.员工变动任务新增该员工兼职信息，自动处理。绩效档案也新增该员工兼职任职的档案③-0005，任职经历信息为行政组织C相关信息。
9.员工变动任务新增该员工调动流出、流入信息，自动处理。绩效档案变更该员工档案③-0004，升级版本为V0002，显示信息为行政组织Y相关信息。
10.员工变动任务新增该员工兼职信息，自动处理。绩效档案也新增该员工兼职任职的档案③-0006，任职经历信息为行政组织Z相关信息。
11.删除成功
12.任职经历中步骤1、3会实现变更档案，生成版本；步骤5、7实现变更档案，生成版本；步骤6、9实现变更档案，生成版本。其他任职经历全部新增档案。

**用例类型**: 集成测试
