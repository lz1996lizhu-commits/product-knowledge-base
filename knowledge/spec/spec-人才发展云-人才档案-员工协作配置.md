3.1、人才管理组织
默认值设置开关开启：
人才档案.人才管理组织 = 参数 员工默认管理组织
3.2、管理部门
默认值设置开关开启：
人才档案.管理部门 = 参数 任职经历.行政组织
3.3、人才档案分组
默认值设置开关开启：
人才档案.人才档案分组 = 参数 1050_S
3.4、生效日期
默认值设置开关开启：
人才档案.生效日期 = 参数 任职经历.开始时间
3.5、失效日期
默认值设置开关开启：
人才档案.失效日期 = 参数 任职经历.结束时间

## 用例 7835: 人才档案协办任务处理逻辑

**功能路径**: 人才发展云（pro）-人才档案-员工协作配置-协作处理策略-详情页

**功能说明**: 
1、用户有人才档案-员工协作配置的查询权限
2、已选择人才档案-员工协作配置-协作处理策略

**步骤描述**: 
1、协作处理策略配置规则设置-决策集或决策表，填写规则为条件A结果为自动处理
2、协作处理策略配置规则设置-决策集或决策表，填写规则为条件B结果为手动处理
3、协作处理策略配置规则设置-决策集或决策表，填写规则为条件C结果为无需处理
4、协作处理策略配置规则设置-决策集或决策表，填写规则为条件D结果为自动处理，但默认为手动处理

**预期结果**: 
1、使用该规则的方案满足条件A时，生成协作任务并自动处理，字段赋值处理规则按协作规则方案处理
2、使用该规则的方案满足条件B时，生成协作任务需手动处理，字段赋值处理规则按协作规则方案处理
3、使用该规则的方案满足条件C时，生成协作任务标记为已处理，档案字段不会发送变化
4、不满足规则设置中条件D时，则给该系统任务使用默认处理方式 = 手动处理，生成协作任务需手动处理，字段赋值处理规则按协作规则方案处理

## 用例 7842: 人才管理组织+业务对象未匹配到协作应用配置，验证匹配上级BU的协作应用配置

**功能路径**: 人才发展云（pro）-人才档案-员工协作配置-协作应用配置-详情页

**功能说明**: 
1、用户有人才档案-员工协作配置的查询权限
2、已选择人才档案-员工协作配置-协作应用配置

**步骤描述**: 
1、根据任职经历.行政组织查询员工管理关系策略获取人才BU在协作应用配置列表未配置数据
2、若上级BU均未添加协作应用配置
3、若根BU的协作应用配置被禁用

**预期结果**: 
默认查询人才BU的上级BU是否在协作应用配置列表配置数据
1.1、若配置，则取配置下的方案和策略生成变动数据
1.2、若未配置，继续查找上级BU
2、则取预置协作应用配置，即根BU的协作应用配置
3.1、则按照无协作规则方案处理，变动后档案信息字段均为空
3.2、策略默认按手动处理执行
