# 目标绩效云-基础资料按钮通用用例-分配查询（按组织）

用例总数: 1

## 用例 1138: 验证分配查询（按组织）功能

**功能路径**: 目标绩效云(pro)-基础资料按钮通用用例-分配查询（按组织）

**功能说明**: 
用户有正态分布规则列表的操作权限

**步骤描述**: 
1、进入正态分布规则列表，点击分配查询（按组织）
2、勾选组织，点击查询
3、不勾查询出来的数据，点击取消分配
4、勾选查询出来的数据，点击取消分配

**预期结果**: 
1.1、弹窗名称：基础数据分配查询
1.2、左树：目标绩效的组织视图，右表：编码、名称、创建组织、使用组织---表数据默认为空
1.3、按钮：取消，查询（高亮），取消查询（高亮）
右表展示分配组织=所选使用组织，并且已分配组织包含已选组织的数据
黄色提示：请选择要取消分配的数据。
操作成功，已勾选的数据取消分配成功

**用例类型**: 功能测试
