# 人才发展云-干部管理-干部任期初始化

用例总数: 3

## 用例 13763: HR数据迁移中心-迁移对象创建迁移任务后，导入后正常同步数据验证

**功能路径**: 人才发展云（pro）-干部管理-干部任期初始化

**功能说明**: 
当前用户有HR数据迁移中心的查询和操作权限

**步骤描述**: 
HR数据迁移中心-迁移任务页面，选择干部管理初始化的任务点击进入到详情页，导入的数据存在多行数据包含：仅填写了必填项的数据行、未填写必填项的数据行、填写了必填与非必填的全部数据行，导入后同步数据

**预期结果**: 
必填项未填写的数据行未正常导入，其他数据正常导入的页面，
干部任期列表显示的数据与导入的一致，组织分配数据与任职经历id关联的一致；
创建人、修改人赋值未系统账号
创建时间和修改时间等于当前时间
