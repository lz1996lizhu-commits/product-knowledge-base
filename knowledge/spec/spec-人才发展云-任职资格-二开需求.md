# 人才发展云-任职资格-二开需求

用例总数: 2

## 用例 723: 扩展启用插件后，同一员工相同/不同认证标准，提交HR认证申请成功

**功能路径**: 人才发展云（pro）-任职资格-二开需求

**功能说明**: 
1、用户有任职资格的所有操作权限 2、员工张三已存在任职资格标准A，不存在任职资格标准B的认证申请流程

**步骤描述**: 
1、进入【开发服务云】-【开发平台】-【人才发展云】，扩展一个任职资格元数据，搜索认证申请单页面标识kfwd_caqm_cerapplybil_ext，扩展应用并进入，启用插件“kd.tdc.caqm.formplugin.demo.CerApplyRepeatSubmitDemo“并保存
2、进入【人才发展云】-【任职资格】-【资格认证】-【认证申请】页面，点击【新增】/{姓名}热区进入详情页，选择员工张三，任职资格标准为A，相同或不同认证等级，点击【提交】
3、再新增一条数据，选择员工张三，任职资格标准为B，相同或不同认证等级，点击【提交】

**预期结果**: 
1、启用插件并保存成功
2.1、绿色浮层提示“提交成功”
2.2、认证申请列表中新增一条姓名张三、申请认证标准为A、认证状态为认证中的单据
3.1、绿色浮层提示“提交成功”
3.2、认证申请列表中新增一条姓名张三、申请认证标准为B、认证状态为认证中的单据
