# 人才发展云-干部管理-任免OP改造

用例总数: 1

## 用例 21465: 任免流程完成生成附件异常后重试成功验证

**功能路径**: 人才发展云（pro）-干部管理-任免OP改造

**功能说明**: 
用户拥有干部任免流程的所有节点的查看和操作权限

**步骤描述**: 
1、任命提名单流程流转到工作流自动的前一个节点，执行锁表t_cadm_msgmaintain
2、任命提名单提交完成自动节点的前一个单据流程
3、执行解锁表t_cadm_msgmaintain操作
4、工作流服务-监控中心-异常流程信息，勾选步骤2的异常流程点击重新激活
5、执行任期生效的定时任务后检查任期中任免信息附表的数据

**预期结果**: 
1、t_cadm_msgmaintain锁定成功
2、单据提交完成成功；
工作流流转到自动节点异常挂起
3、解锁成功
4、重新激活成功
5、生成对应的任期数据后任免附表中公示、签发、发布正常生成了附件，工作流显示正常流转
5.1、中间表t_tdcs_relational、t_tdcs_dismissrelation数据拉取、关联任免单正常，未生成重复的数据
